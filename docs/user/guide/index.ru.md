# Использование веб-интерфейса

[English](index.md) | [中文](index.zh.md) | Русский

Запустите веб-интерфейс согласно [корневому README](../../../README.ru.md#запуск); команда выведет его URL. Это руководство начинается с момента, когда сервер уже работает. Процесс `dsh` использует каталог запуска как расположение по умолчанию в файловой системе, но в свежем веб-интерфейсе рабочая область не выбрана, пока вы её не добавите.

## Настройте модель

Откройте **Settings → Models**, введите [API-ключ DeepSeek](https://platform.deepseek.com/) и сохраните его. Маршрут модели становится пригоден к использованию сразу, без перезапуска сервера.

[Руководство по настройке моделей](./providers.ru.md) описывает других провайдеров и пользовательские эндпоинты, совместимые с OpenAI.

## Выберите рабочую область

Нажмите **Choose workspace**, добавьте каталог проекта, в котором вы запустили `dsh`, и выберите его. Компоновщик сессии остаётся недоступным, пока не выбрана рабочая область.
