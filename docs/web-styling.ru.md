# Стилевой справочник Web UI

[English](web-styling.md) | [中文](web-styling.zh.md) | Русский

Этот справочник определяет владение стилями и правила компонентов для пакетов браузерного клиента. Текущие значения токенов живут в [`packages/client/ui-theme/src/styles/`](../packages/client/ui-theme/src/styles/); этот документ не дублирует тот порождаемый исходниками реестр.

## Владение

[`ui-theme`](../packages/client/ui-theme/README.md) владеет статической шкалой `--dsw-*`, семантическими алиасами, типографикой, движением, градиентами, тенями, стилями скроллбаров и предпочтением светлое/тёмное. [`ui-layout`](../packages/client/ui-layout/README.md) применяет разрешённый снимок темы к документу. Фичевые пакеты потребляют семантические алиасы и не определяют ещё одну глобальную тему.

Глобальные таблицы стилей принадлежат `ui-theme/src/styles/`. Стили компонентов живут рядом с компонентом как CSS Modules. Компонент может определить локальную custom-property, когда её значение — часть контракта компоновки или представления этого компонента; общие цвета, типографика, возвышение и движение принадлежат пакету темы.

## Правила компонентов

- Используйте CSS Modules и `clsx`; не добавляйте библиотеку компонентов или Tailwind.
- В фичевых компонентах используйте семантические токены `--dsw-alias-*`. Не копируйте туда значения статической палитры и не пишите литеральные цвета.
- Держите селекторы темы вне CSS фичевых компонентов. Переопределения светлое/тёмное принадлежат владельцу темы.
- Сопоставляйте размеры шрифта с межстрочными интервалами и используйте типографские переменные темы, когда существующая роль подходит.
- Держите исходный текст, вывод терминала и строки diff неразорванными, когда контракт компонента требует сохранения колонок; используйте общие стили скроллбаров вместо компонентных селекторов скроллбара.
- Помещайте представление в CSS. Инлайновые React-стили могут передавать значения component-local custom-property, но не должны кодировать ветвления темы.
- Сохраняйте видимость клавиатурного фокуса и поведение reduced-motion при добавлении переходов или hover-only элементов управления.

## Изменение системы

Добавьте или измените общий токен в владеющем листе `ui-theme`, затем потребляйте его семантический алиас из фичевых пакетов. Обновляйте справочник владеющего пакета при изменении публичного стилевого контракта. Визуальное поведение следует [тестовой политике](testing.md); Agent Note о [стилевой системе](../.agents/notes/implemented/process/2026-07-19-web-styling-system.md) хранит обоснование выбора каркаса.
