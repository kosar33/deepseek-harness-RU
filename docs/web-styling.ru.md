# Стилевой справочник Web UI

[English](web-styling.md) | [中文](web-styling.zh.md) | Русский

Этот справочник определяет владение стилями и правила компонентов для пакетов браузерного клиента. Текущие значения токенов находятся в [`packages/client/ui-theme/src/styles/`](../packages/client/ui-theme/src/styles/); этот документ не дублирует порождаемый из исходников перечень.

## Владение

[`ui-theme`](../packages/client/ui-theme/README.ru.md) владеет статической шкалой `--dsw-*`, семантическими алиасами, типографикой, движением, градиентами, тенями, стилями скроллбаров и предпочтением светлой или тёмной темы. [`ui-layout`](../packages/client/ui-layout/README.ru.md) применяет к документу разрешённый снапшот темы. Фичевые пакеты потребляют семантические алиасы и не определяют ещё одну глобальную тему.

Глобальные таблицы стилей размещаются в `ui-theme/src/styles/`. Стили компонентов живут рядом с компонентом как CSS Modules. Компонент может определить локальную custom-property, когда её значение — часть контракта компоновки или представления этого компонента; общие цвета, типографика, возвышение и движение принадлежат пакету темы.

## Правила компонентов

- Используйте CSS Modules и `clsx`; не добавляйте библиотеку компонентов или Tailwind.
- В фичевых компонентах используйте семантические токены `--dsw-alias-*`. Не копируйте туда значения статической палитры и не задавайте цвета литерально.
- Держите селекторы темы вне CSS фичевых компонентов. Переопределения светлой/тёмной темы принадлежат владельцу темы.
- Сопоставляйте размеры шрифта с межстрочными интервалами и используйте типографские переменные темы, когда существующая роль подходит.
- Не переносите строки исходного текста, вывода терминала и diff, когда контракт компонента требует сохранения колонок; используйте общие стили скроллбаров вместо компонентных селекторов скроллбара.
- Помещайте представление в CSS. Инлайновые React-стили могут передавать значения локальных custom-property компонента, но не должны реализовывать ветвления темы.
- Сохраняйте видимость клавиатурного фокуса и поведение reduced-motion при добавлении переходов или hover-only элементов управления.

## Изменение системы

Добавьте или измените общий токен в принадлежащей `ui-theme` таблице стилей, затем потребляйте его семантический алиас из фичевых пакетов. Обновляйте справочную документацию пакета-владельца при изменении публичного стилевого контракта. Визуальное поведение следует [тестовой политике](testing.ru.md); Agent Note о [стилевой системе](../.agents/notes/implemented/process/2026-07-19-web-styling-system.md) хранит обоснование устройства этой системы.
