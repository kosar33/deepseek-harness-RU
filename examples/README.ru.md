# Примеры

[English](README.md) | [中文](README.zh.md) | Русский

Запускаемые демонстрации основных интерфейсов и точек расширения DeepSeek Harness. Каждый вложенный каталог владеет своей конфигурацией, предварительными требованиями, командами и подробным описанием поведения.

## mcp-memory

Необязательные оверлеи, подключающие поддерживаемые сторонние серверы памяти через универсальный MCP-клиент. См. [описание примера памяти](mcp-memory/README.ru.md).

## headless-agent

Неинтерактивный агент, который принимает одну задачу, выполняет её и выдаёт результат в выбранном машиночитаемом или человекочитаемом формате. См. [описание headless-примера](headless-agent/README.ru.md).

## jsonrpc-agent

Агент для написания кода, работающий без участия человека и управляемый через Python SDK и JSON-RPC. См. [описание JSON-RPC-примера](jsonrpc-agent/README.ru.md).

## web-cordis

Самореферентный агент, способный просматривать и изменять своё дерево плагинов Cordis в памяти. См. [описание примера web-cordis](web-cordis/README.ru.md).

## web-schedule

Опциональный веб-оверлей для долговечных напоминаний, локальных для сессии. Через `schedule_create`, `schedule_list` и `schedule_delete` он поддерживает положительные задержки `after_seconds`, кратные целым секундам, и абсолютные цели `at`; активные напоминания сохраняются в исходной сессии, возобновляются, когда она снова становится активной, и не выполняются, пока сессия остаётся холодной. Запустите `dsh web --patch examples/web-schedule/cordis.yml`; об источнике истины для абсолютного времени, доставке и границах восстановления см. [web-schedule/README.ru.md](web-schedule/README.ru.md).

## acp-agent

Сервер автоматизации Agent Client Protocol (ACP) для программных клиентов с поддержкой сессий, разрешений и отмены. См. [описание ACP-примера](acp-agent/README.ru.md).
