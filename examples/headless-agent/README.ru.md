# headless-agent

[English](README.md) | [中文](README.zh.md) | Русский

Этот каталог владеет композицией для воспроизведения и тестов с реальной моделью для headless-агента написания кода: DeepSeek V4 + локальные инструменты bash и файловой системы + делегирование субагентам + воркфлоу и итерация Ralph со свежими агентами + `todo_write` + персистентность JSONL. Он явно монтирует общий агентский стержень, один корневой агент, персистентность и политику чекпоинтов; это не вторая точка входа продукта.

## Запуск

```sh
# repo root .env (gitignored) or exported env:
#   DEEPSEEK_API_KEY=sk-…
#   DEEPSEEK_BASE_URL=https://…   # optional; defaults to the public API
pnpm dsh --profile headless "fix the failing test in this workspace"
```

Продуктовая команда — [`dsh --profile headless`](../../apps/cli/README.md): она принимает одну непустую задачу, создаёт и сохраняет свежую сессию, печатает финальный текст ассистента и завершается.

Снапшот-наборы прогоняют конфигурацию этого каталога через [`tests/fixtures/headless-driver.ts`](tests/fixtures/headless-driver.ts) — неотэкспортируемый процесс только для тестов, который выдаёт канонические события сессии в JSONL перед своей итоговой записью результата. Этот поток — тестовая инфраструктура, а не поддерживаемый формат вывода CLI. Дочерние сессии проявляются только через события и результаты родительских инструментов.

## Оверлей POC E2B

[`e2b.cordis.yml`](e2b.cordis.yml) заменяет локальных провайдеров файловой системы и подпроцессов единой общей песочницей E2B, сохраняя `dsh-bash-local` и те же видимые модели инструменты. Положите `E2B_API_KEY` рядом с `DEEPSEEK_API_KEY` в игнорируемый git корневой `.env`, затем запустите живую композицию, требующую учётных данных: она водит FS, Bash, PTY и LSP в одной песочнице и доказывает финальное удаление:

```sh
pnpm exec vitest run --config vitest.e2e.config.ts packages/e2b/e2b/tests/composition.e2e.ts
```

Оверлей создаёт внутри песочницы тот же абсолютный cwd, но не выгружает и не монтирует рабочее пространство хоста. Изменения файлов и Bash существуют только в E2B; Cordis, вызовы моделей, состояние агентов и сессий, журналы сессий, скиллы и буферы SDK остаются на хосте. Композиция завершает свою песочницу при тайм-ауте и освобождении ресурсов. Это POC композиции провайдеров, а не миграция всего harness или функция синхронизации рабочего пространства.
