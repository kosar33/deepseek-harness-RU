# jsonrpc-agent

[English](README.md) | [中文](README.zh.md) | Русский

Композиция агента написания кода без участия человека для встроенного JSON-RPC-рантайма Python SDK. Она намеренно не загружает ни терминальный UI, ни консольный логгер, ни UI одобрения, ни инструмент вопросов к пользователю, потому что stdout принадлежит протоколу SDK, а ходами управляет SDK.

Инструменты, видимые модели:

- `bash`, только на переднем плане
- `read`, `write` и `edit`
- `subagent`, использующий единственный внутрипроцессный провайдер запуска на переднем плане
- `todo_write`

Окружающий рантайм также загружает персистентность сессий JSONL и автоматическую компакцию контекста. Параметр `maxTokensAsSuccess` сохраняет ход модели, оборванный лимитом токенов, как принятый результат оценки, сохраняя его причину завершения `max-tokens`.

## Окружение рантайма

| Переменная | Назначение |
|---|---|
| `DEEPSEEK_API_KEY` | Учётные данные, передаваемые OpenAI-совместимой конечной точке |
| `DEEPSEEK_BASE_URL` | Конечная точка, которую использует `dsh-llm-deepseek` |
| `DSH_CWD` | Рабочее пространство агента для инструментов bash и файловой системы |
| `DSH_CONTEXT_WINDOW` | Ёмкость контекста, записываемая в запись каталога для `DSH_MODEL` в минимальном варианте |
| `DSH_MAX_TOKENS_AS_SUCCESS` | `true` (по умолчанию) принимает результаты, ограниченные по токенам; `false` сообщает о них как об ошибках |
| `DSH_MODEL` | Модель по умолчанию, используемая `minimal.py`; `--model` имеет приоритет |
| `DSH_SESSION_ROOT` | Каталог JSONL-сессий |
| `DSH_SYSTEM_PROMPT` | Заданная развёртыванием персона для написания кода |

Передайте путь к конфигурации через опцию `cordis` Python SDK или переменную `DSH_CORDIS_CONFIG`. Входящий в комплект исполняемый файл уже содержит каждый плагин, названный в этом файле; целевой машине не нужен Node.js.

## Минимальный вариант

[`minimal.cordis.yml`](minimal.cordis.yml) — полный автономный аналог пресета `minimal` веб-приложения. `DSH_SYSTEM_PROMPT` выбирает его системный промпт; запасным вариантом служит `You are a helpful software engineer assistant.`. Этот вариант подавляет все вклады рантайм-контекста в системный промпт для свежих сессий и не монтирует плагин компакции контекста. Его видимые модели инструменты — ровно следующие:

- персистентный `bash`, ограниченный владельцем
- `str_replace_editor` с `view`, `create`, `str_replace` и `insert`

Он собирает локальный PTY, простой бэкенд `fs-local`, политику danger-full-access для персистентного Bash и несжатую персистентность JSONL, нужные встроенному рантайму. Пути Bash и абсолютные пути редактора могут изменять любой путь, доступный процессу рантайма, поэтому запускайте этот вариант только на одноразовой рабочей копии или в контейнере. Персистентный PTY требует POSIX-окружения терминала и не является интерфейсом агента для Windows.

[`minimal.py`](minimal.py) запускает композицию через Python SDK и использует `DSH_MODEL` как модель по умолчанию. [Руководство по Python SDK](../../docs/user/guide/python-sdk.ru.md) охватывает установку, запуск, выбор рабочего пространства и идентичность сессий; [справочник SDK](../../python/sdk/README.ru.md) владеет жизненным циклом рантайма и семантикой результатов.
