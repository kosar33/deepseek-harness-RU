# web-cordis

[English](README.md) | [中文](README.zh.md) | Русский

Самореференциальная демонстрация [`@deepseek-ai/dsh-tool-cordis`](../../packages/extensions/tool-cordis/README.ru.md). Агент может осматривать текущий процесс Cordis и монтировать или размонтировать написанные моделью плагины в памяти. Временные плагины исчезают при размонтировании или завершении процесса и могут влиять на другие сессии того же процесса.

## Запуск

Запустите браузерный интерфейс:

```sh
pnpm run demo:cordis
```

Вместо этого запустите сервер автоматизации ACP:

```sh
pnpm run demo:cordis acp
```

Обе команды требуют `DEEPSEEK_API_KEY`. [Справочник инструмента Cordis](../../packages/extensions/tool-cordis/README.ru.md) определяет контракты аргументов, времени жизни, очистки и безопасности инструмента.
