# native/

[English](README.md) | [中文](README.zh.md) | Русский

Нативные исходники и публичные пакеты, сопровождаемые вместе с DeepSeek Harness. [Workspace `landlock-run/`](landlock-run/README.ru.md) владеет лончером самограничения Landlock с последующим запуском, используемым harness, — включая его архитектуру, семейство из трёх npm-пакетов, поддержку платформ, процесс разработки и [процедуру выпуска](landlock-run/docs/release.md).

## Границы workspace и выпуска

`landlock-run/` и его пакеты принадлежат корневому pnpm-workspace и lockfile репозитория. Потребители harness во время разработки и CI используют текущий входной пакет из workspace, поэтому изменение контракта лончера и обновление его потребителя могут попадать и проверяться вместе.

Workflow `Landlock Run` главного репозитория собирает и тестирует каждую поддерживаемую архитектуру. `Landlock Run Release` собирает эти нативные артефакты, пакует и проверяет три npm-tarball'а, затем опционально публикует их под одной версией лончера. Входной пакет объявляет платформенные пакеты как npm optional dependencies, так что npm по-прежнему устанавливает только пакет под операционную систему и CPU пользователя.
