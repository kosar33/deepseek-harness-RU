# Контракт CLI: landlock-run

[English](cli-contract.md) | Русский

Этот файл фиксирует внешне наблюдаемое поведение лаунчера — межрепозиториальную поверхность совместимости между бинарниками и каждым потребителем. Потребители работают с ним через входной пакет (`launcherPath`/`probe`/`grantArgs`) и протокол лаунчера; изменение чего-либо из перечисленного ниже требует поднятия версии всего семейства пакетов и заметки в release notes.

## Грамматика вызова

```text
landlock-run [--ro <path>]... [--rw <path>]... -- <argv>...
landlock-run --probe
```

- `--ro <path>`: выдаёт право чтения и исполнения ниже `<path>`.
- `--rw <path>`: выдаёт полный доступ к файловой системе ниже `<path>` (весь спектр доступов, которым может управлять согласованный ABI ядра).
- Всё не выданное — запрещено: наборы правил Landlock являются разрешающими списками (allow-list).
- Право на не-каталоге сохраняет только совместимые с файлом биты доступа (так работает право `--rw /dev/null`).
- `--`: обязательный разделитель; всё после него — argv команды, запускаемой через `execvp` с неизменным окружением лаунчера.
- `--probe`: взаимоисключающ с правами и командой.
- Никаких других флагов, никаких входных данных из переменных окружения.

## Коды выхода

- `125` (`LAUNCHER_FAILURE_EXIT`): любая ошибка уровня лаунчера — ошибка использования, ядро, не способное исполнять Landlock, неоткрываемый корень выдачи прав, неудавшийся `exec`. Обёрнутая команда НЕ запускалась.
- После успешного `exec` любой статус потомка проходит насквозь без изменений, включая 125. Поэтому потребители ДОЛЖНЫ опираться на оба признака сразу — статус 125 и фатальную строку с префиксом `landlock-run: `, — чтобы атрибутировать сбой лаунчера.
- `--probe`: `0`, когда ядро исполняет правила (полностью или частично), иначе `125`.

## Отчётные строки

- Успешный probe печатает ровно одну строку в stdout: `landlock: fully enforced` или `landlock: partially enforced (older ABI)`. Функция `probe()` входного пакета отображает их в `full`/`partial`; ненулевой код выхода probe отображается в `unusable`.
- Изолированный запуск под ядром с частичным ABI печатает одну строку в stderr `landlock-run: partial enforcement (older Landlock ABI)` и продолжает работу — оставаясь изолированным во всём, что ядро поддерживает.
- Каждая фатальная ошибка печатает одну строку в stderr с префиксом `landlock-run: ` перед выходом с кодом `125`.

## Семантика ограничения

Лаунчер выставляет `no_new_privs`, устанавливает набор правил на самого себя и запускает команду через `exec`; набор правил наследуется через `execve`, поэтому каждый процесс-потомок изолирован в равной мере. Набор правил управляет доступами к файловой системе согласно согласованному ABI Landlock ядра (до ABI 5); доступы новее работающего ABI не управляются — на этом разница между `full` и `partial`.
