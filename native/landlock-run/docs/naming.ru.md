# Именование

[English](naming.md) | Русский

## npm-пакеты

Публичное семейство пакетов принадлежит скоупу `@deepseek-ai` и носит префикс пакетов `node-addon-landlock-run`; платформенные пакеты лишь добавляют к имени сведения о платформе:

```text
@deepseek-ai/node-addon-landlock-run
@deepseek-ai/node-addon-landlock-run-<platform>
```

В суффиксах платформ нет ни libc-компоненты (бинарники — статический musl), ни обозначения варианта: варианты живут внутри `prebuilds.json` и в именах файлов бинарников.

## Бинарники

Исполняемый файл лаунчера называется `landlock-run` и поставляется по пути `bin/landlock-run` внутри каждого платформенного пакета.

## Переменные окружения

Префикс `NALR_` (Node Addon Landlock Run) зарезервирован за оркестрацией сборки и тестирования:

```text
NALR_REQUIRE_LANDLOCK   test-only: an unenforcing kernel fails instead of skipping
```

Рантаймные бинарники и входные пакеты не читают НИ ОДНОЙ переменной окружения — это правило безопасности рантайма ([AGENTS.md](../AGENTS.md)), а не соглашение об именовании. Не включайте npm-скоуп в имена переменных окружения.

## Символы C

Лаунчер представляет собой один C-файл со статической компоновкой, поэтому пространства экспортируемых символов у него нет. Константы UAPI ядра там, где они определены локально, сохраняют свои имена из ядра с префиксом `LL_`.
