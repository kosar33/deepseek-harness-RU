# Матрица поддержки

[English](support-matrix.md) | Русский

## Поддерживается

| Платформенный пакет | Раннер GitHub (канонический сборщик) | Примечания |
|---|---|---|
| `@deepseek-ai/node-addon-landlock-run-linux-x64` | `ubuntu-24.04` | статический musl — одинаково для дистрибутивов glibc и musl |
| `@deepseek-ai/node-addon-landlock-run-linux-arm64` | `ubuntu-24.04-arm` | статический musl — одинаково для дистрибутивов glibc и musl |

Для принудительного исполнения вдобавок требуется ядро с включённым Landlock (5.13+). Вердикт probe определяет согласованный уровень ABI: если управляются все доступы, о которых знает эта сборка, — `full`; более старый ABI, управляющий подмножеством доступов, — `partial` (ограничение всё равно действует для всего, что он поддерживает); Landlock отсутствует или отключён — `unusable`, и лаунчер вовсе отказывается запускать команды. Авторитет здесь — сам probe, а не версия ядра: ядро, собранное без Landlock или с отключённым LSM, даст `unusable` независимо от своей версии.

## Намеренно не поддерживается

- **darwin**: потребители на macOS обычно ограничивают процессы через `sandbox-exec`/Seatbelt, что входит в состав самой ОС, — распространяемого бинарника просто нет.
- **win32**: лаунчер ограничения для Windows стал бы отдельным механизмом в собственном репозитории, а не портом этого.
- **Другие архитектуры Linux** (riscv64, s390x, …): канонического нативного CI-сборщика пока нет. Согласно правилу отсутствия кросс-тулчейнов, платформенный пакет добавляется только вместе с нативным раннером, который его собирает и доказывает его работоспособность.

Потребитель на неподдерживаемой платформе разрешит несуществующий путь лаунчера, получит от probe `unusable` и завершится по fail-closed — это задокументированная деградация, которую отрабатывает darwin-плечо CI.
