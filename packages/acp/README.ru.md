# acp/ — автоматизация по Agent Client Protocol

[English](README.md) | [中文](README.zh.md) | Русский

Группа ACP открывает агентов harness программным клиентам поверх протокола Agent Client Protocol (ACP). Это транспорт совместимости, а не слой представления и не слой взаимодействия с человеком; парный ему внепроцессный субагент-*клиент* находится в [`subagent/subagent-acp`](../subagent/subagent-acp/README.ru.md), поскольку он реализует интерфейс провайдера субагентов.

| Пакет | Роль |
|---|---|
| [`acp/`](acp/README.ru.md) | ACP-сервер, работающий только в сценариях автоматизации. |

Контракт сервера описан в [`acp/README.md`](acp/README.ru.md).
