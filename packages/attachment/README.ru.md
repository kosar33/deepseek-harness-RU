# attachment/ — семейство возможностей долговечных вложений

[English](README.md) | [中文](README.zh.md) | Русский

Capability seam долговечных двоичных вложений и его локальная реализация поверх файловой системы. Оба пакета — продуктовые.

| Пакет | Роль | Ключ ctx |
|---|---|---|
| `attachment/` | Неизменяемые ссылки на вложения, ограничения для изображений и сервис хранилища | `ctx.attachments` |
| `attachment-local/` | Хранилище с адресацией по содержимому внутри `DSH_HOME` | (регистрируется в `ctx.attachments`) |

Неотправленные черновики браузера сознательно находятся вне этой возможности. Байты попадают в долговечное хранилище только после отправки пользовательского промпта либо когда адаптер провайдера фиксирует структурированный вывод модели.
