# boot/ — общая загрузочная обвязка исполняемых файлов приложений

[English](README.md) | [中文](README.zh.md) | Русский

Нейтральная к каналам загрузочная библиотека, общая для `apps/cli` и демонстрационных исполняемых файлов из [`examples/`](../examples/README.md).

| Пакет | Роль | Ключ ctx |
|---|---|---|
| `app-boot/` | Общая загрузочная обвязка исполняемых файлов приложений: загрузка `.env`, fail-loud-защиты Loader, разрешение конфигурации с учётом снапшота, загрузочная последовательность, доводящая дерево до quiescence | (библиотека для исполняемых файлов) |
| `cmdline/` | Передача командной строки от лаунчера приложению и принадлежащий приложению разбор параметров запуска | `cmdlineArgs`, `appExit` |

Последовательность загрузки и контракт личной конфигурации описаны в [`app-boot/README.md`](app-boot/README.ru.md); командные строки, принадлежащие приложениям, описаны в [`cmdline/README.md`](cmdline/README.ru.md).
