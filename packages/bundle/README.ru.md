# bundle/ — профильные плагин-бандлы

[English](README.md) | [中文](README.zh.md) | Русский

Профильные бандлы: npm-пакеты, чей манифест объявляет `"dsh": { "bundle": { "patch": "./cordis.patch.yml" } }`, что делает их устанавливаемыми слоями патчей для композиций `dsh --profile` ([контракт профилей](../boot/app-boot/README.ru.md#профили)). Сущность бандла — его список патчей; некоторые также поставляют рантайм-плагины обвязки, которые их патч монтирует.

Идентичность Bundle определяет декларация в манифесте, а не этот каталог. Пакеты предметной области могут нести собственный необязательный слой Profile; [пакеты субагентов Codex и Claude Code](../subagent/README.ru.md) — примеры, устанавливаемые напрямую.

| Пакет | Роль | Ключ ctx |
|---|---|---|
| [`base/`](base/README.ru.md) | Общее ядро dsh, которое каждый профиль применяет первым | — (только патч) |
| [`web-app/`](web-app/README.ru.md) | Браузерный облик: слой веб-патча + рантайм-плагин обвязки | монтирует строки |
| [`headless/`](headless/README.ru.md) | Прямой режим одноразовых задач поверх base, без слоёв Host или Web | монтирует `headless-runner` |

Встроенные бандлы разрешаются из самой установки dsh; внешние бандлы устанавливаются в профиль командой `dsh plugin --profile <name> add <package>`.
