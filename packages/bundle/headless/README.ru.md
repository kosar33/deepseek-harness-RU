# `@deepseek-ai/dsh-headless`

[English](README.md) | [中文](README.zh.md) | Русский

Бандл dsh для одноразовых задач. [`cordis.patch.yml`](cordis.patch.yml) ложится прямо поверх [`dsh-base`](../base/README.ru.md): он задаёт персону для программирования и режим инструментов, отключает HMR, монтирует воркер Code Mode как базовую возможность исполнения и вставляет плагин `headless-runner` этого пакета (конфиг `{task}`, разрешаемый из внедрённого провайдера `headlessStartup`). Он не монтирует ни Host, ни HTTP-сервер, ни веб-рантайм, ни браузерный плагин.

После того как Loader доведёт дерево до quiescence, раннер читает общий [`ctx.agentDefaultModel`](../../core/agent-default-model/README.md), создаёт один новый персистентный Agent через `ctx.agents`, отправляет задачу как обычное пользовательское сообщение и ожидает quiescence. Он сбрасывает Session до сворачивания принадлежащего ему долговечного интервала событий, пишет последний непустой текст ассистента в stdout и запрашивает выход через предоставленный лаунчером хост-хук `ctx.appExit` ([`dsh-cmdline`](../../boot/cmdline/README.ru.md)) (финальный завершённый `turn/end` → 0, иначе 1). Терминальная причина `error` дополнительно пишет свой код и сообщение в stderr; успешные запуски оставляют stderr пустым. Процесс не открывает ни одного прослушиваемого порта. Текст задачи — это командная строка данного приложения: обычный провайдер `headless-startup` ([`src/startup.ts`](src/startup.ts)) внедряет `ctx.cmdlineArgs` ([`dsh-cmdline`](../../boot/cmdline/README.ru.md)), читает позиционный аргумент `dsh --profile headless "task"`, печатает `--help` приложения и предоставляет `headlessStartup`; раннер внедряет этот сервис и читает свою задачу из ленивой конфигурации. Отсутствующая или состоящая из одних пробелов задача отвергается до активации раннера.

## Model Experience

Отсутствует: раннер отправляет задачу как обычное пользовательское сообщение; промпты и инструменты принадлежат строкам бандлов base и headless.

#### KV Cache effect

Отсутствует; раннер ничего не добавляет в префикс запроса.

## Известные ограничения и отложенная работа

- **Только одна отправленная задача** — у раннера нет интерактивного канала для последующих обращений; он дожидается всей работы, которую завершит Agent, прежде чем вернуться в состояние простоя, и печатает последнее непустое сообщение ассистента за этот интервал.
- **`ctx.appExit` принадлежит лаунчеру** — запуск headless-профиля вне лаунчера `dsh` падает по fail-loud при активации, пока хост не предоставит запрос на выход.
