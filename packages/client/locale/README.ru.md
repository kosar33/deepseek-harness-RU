# @deepseek-ai/dsh-client-locale

[English](README.md) | [中文](README.zh.md) | Русский

Плагин локали: LocaleRuntime — предпочтение `zh`/`en`/`ru`, хранимое как `locale.preference` в `$DSH_HOME/settings.yaml`; когда явного значения Host нет, свежий браузер стартует предварительно на том языке, о котором просит `navigator` (сопоставление по первому подтегу, с `en`, если он не просит ни одного языка, который это приложение поставляет). Чтение на Host выполняется после активации плагина, поэтому недоступный сервис настроек не может заблокировать страницу; его результат живьём заменяет предварительное браузерное значение. Удалённые браузеры удерживают лишь выбор уровня процесса, потому что API настроек доступен только на loopback. `locale/change` срабатывает при переключениях, а плагин направляет `<html lang>` на активную локаль (`zh-CN`/`en`/`ru`) при активации и при каждом переключении. Сервис также владеет реестром словарей ns×locale (типизированный `register(ns, {zh, en, ru})`, проверяемый по `LocaleNamespaceMap`; `bind(ns)`→`TranslateNS<ns>`; цепочка поиска ns → common → en → key), реализует `LocaleFace` системы slot'ов и устанавливает себя через `ctx.slots.installLocale`, подпирая внедряемый каркасом стандартный стул `t` (`Translate`/`TranslateNS` — типы ui-slots; импортируйте их оттуда — этот пакет лишь реэкспортирует их для удобства владельцев словарей). Границу персистентности закрепляет [решение о Host-подпираемых предпочтениях](../../../.agents/notes/implemented/bug-fix/2026-08-06-host-backed-web-preferences.md).

## Опыт модели

Отсутствует: реестр локалей обслуживает тексты браузерного UI; ничто отсюда не достигает запроса к модели.

#### Влияние на KV-кэш

Отсутствует; этот пакет ни собирает, ни отправляет запрос провайдеру.

## Известные ограничения и отложенная работа

- **Некоторые поверхности удерживают встроенные тексты** — строки Settings, сайдбар, композер вопросов и селектор моделей пользуются местами локали; прочие пакеты всё ещё владеют статическим текстом напрямую.
- **Удерживаемый реестром текст читает свой перевод однажды** — копия, захваченная при регистрации вне пути рендера slot'а (например, описание команды `/model` в реестре команд), сохраняет язык, под которым была зарегистрирована, до перерегистрации; копия, отрисованная через slot, следует за переключениями живьём.
