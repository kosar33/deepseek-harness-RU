# @deepseek-ai/dsh-client-ui-brand-official

[English](README.md) | [中文](README.zh.md) | Русский

Этот пакет заполняет `sidebar.brand.mark`, `sidebar.brand.name` и `conversation.hero.brand.mark`, только когда `DSH_CLIENT_BUILD_PROFILE` равен `official`. Прочие сборки загружают плагин, но не регистрируют ни одного заполнителя, оставляя видимыми запасные варианты оболочки.

Три заполнителя устанавливаются одним набором регистраций, учитывающим объявления, через вложенные вызовы `slots.inject()`. Поэтому пакет работает и когда его строка активируется до объявителей sidebar и conversation, и после них, снимает всех заполнителей, когда любое из объявлений схлопывается, и не оставляет частичной брендовой смеси во время HMR. Он не хранит рантайм-состояния. Узловая половина — пустое место Loader'а, а заголовок браузера остаётся вопросом среды сборки вне этого пакета.

## Model Experience

Отсутствует: пакет добавляет только браузерную презентацию; ничто отсюда не достигает запроса к модели.

#### KV Cache effect

Никакого; этот пакет не собирает и не отправляет запрос к провайдеру.

## Известные ограничения и отложенная работа

- **Пакет поставляет один набор заполнителей** — альтернативная презентация принадлежит другому пакету Cordis, заполняющему те же slot'ы.
- **Заголовок браузера независим** — `DSH_CLIENT_TITLE` выбирает текст заголовка во время сборки, а не через UI-slot.
