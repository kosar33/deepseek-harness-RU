# @deepseek-ai/dsh-client-ui-commands

[English](README.md) | [中文](README.zh.md) | Русский

Клиентский командный API (`ctx.commandUi`): кэш каталога команд с ключом по сессии, источник команд `/` с решающими крюками `matchSpace`/`matchEnter`, диспетчеризация трёх видов (`execute` / `popupSelect` / `leadingInput`) и регистрация popupSelect для бизнес-пакетов. Решение записывает [Agent Note о веб-командах](../../../.agents/notes/implemented/architecture/2026-07-25-web-command-surfaces-and-assembly.md).

`src/client/contract.ts` — фиксированный бизнес-контракт: `CommandUiContract.register(name, spec)` и `decorate(name, spec)` — всё, что потребляет бизнес-пакет; `CommandUiSpec{options, onSelect}` держит данные попапа самодостаточными — компонент оболочки принадлежит этому пакету, и бизнес-пакеты никогда его не видят. Вклад — команда во владении клиента (коллизия имени с хостом терпит громкий отказ); декорация добавляет попап голого вызова к СУЩЕСТВУЮЩЕЙ команде хоста. Хост сохраняет свою строку каталога, притязание на аргумент (space / Enter с аргументом) и логирование жизненного цикла, а декорированное имя без строки хоста в каталоге сессии никогда не срабатывает. Виды команд выводятся на каждую диспетчеризацию, а не при регистрации: дескриптор хоста с `input` — это `leadingInput`, зарегистрированный `CommandUiSpec` — `popupSelect`, а всё остальное — `execute`.

`CommandDirectory` (`src/client/directory.ts`) — единственный выведенный из протокола кэш с ключом по сессии. Обычные сессии забирают его через `command.list({sessionId})`, а рождающийся вместе со scope крюк `warm` источника прогревает запись сессии. Адресуемые каталогом продолжаемые дети разрешают пустой каталог команд локально: `command.list` привязан к Agent'у, поэтому его прогрев активировал бы ребёнка лишь ради просмотра персистентной истории. Записи мягко инвалидируются пробрасываемым событием-владельцем `commands/change` (пока повторная выборка летит, служат старые снапшоты) и пробрасываемым `agent-preset/selected` для той единственной сессии (пересобирающая агента композиция ничего не регистрирует, поэтому реестрово-широкий сигнал для неё никогда не срабатывает), жёстко инвалидируются `connection/reset` и охраняются эпохой, так что вытесненная выборка никогда не перезапишет более новую. `matchSpace` отвечает синхронно только из этого кэша; `matchEnter` сильно ждёт его по сигналу SubmitAttempt и отвергается при отказе прогрева — строка `/` никогда не деградирует молча до обычного промпта.

`matchEnter` также принуждает конверт отправки: когда композер отправляет с вложениями изображений, идёт вперёд только команда хоста, объявляющая `input.images` (её притязание несёт `images: true`, а её отправка пересылает сериализованные полезные нагрузки в `command.execute`); всякий прочий командный маршрут — попап вклада, декорированный попап, необъявляющее притязание, голый отсоединённый execute — бросает локализованный отказ `notice.imagesUnsupported`, который машина ввода публикует одним уведомлением об ошибке, а композер рендерит мимолётным баннером Toast с сохранёнными черновиком и изображениями. Отправка с изображениями, чей обработчик хоста отвечает результатом-ошибкой, отображается в исход «ошибка», чтобы композер сохранил изображения; отправки без изображений сохраняют обычное отображение успеха, потому что рендерингом исхода владеет долговечный узел потока.

После того как `command.execute` вернул результат совпавшей команды, этот браузер испускает локальное `command/executed(sessionId, name, result)`. Другие клиенты получают долговечные командные узлы через поток событий Host, но никогда этого подтверждения, поэтому браузерный побочный эффект может отбирать удачные результаты у клиента, отправившего команду, не принимая воспроизведение Session за запрос действия. Отказы слушателей логируются и содержатся по одному; они не могут изменить уже допущенный результат команды или помешать запуску позднейших слушателей.

Запросы меню нечётко сопоставляют упорядоченные подпоследовательности имён команд без учёта регистра. Префиксы ранжируются первыми; границы разделителей, смежные символы и меньшие промежутки ранжируют остальные совпадения, причём ничьи разрывает порядок каталога и вкладов. Это влияет только на обнаружение: space и Enter по-прежнему требуют точного имени команды. Обоснование: [нечёткое обнаружение веб-slash-команд](../../../.agents/notes/implemented/feature/2026-08-04-web-slash-command-fuzzy-discovery.md).

`PopupSelectController` (`src/client/popup.ts`) — безголовое состояние оболочки: `PopupSelectView` саморегистрируется в `conversation.input.overlay` (ключ SlotMap принадлежит ui-conversation; этот пакет подтягивает объявление type-only импортом — без рантаймного ребра). Оболочка — мимолётный слой, держащий фокус, пока открыта; потребление сегментов токенов после onSelect проводит обе ветви через `consumeTokenSegment` (CAS диапазона для пути меню, равенство голого токена для пути Enter) против грани черновика, которую привязывает слой проводки через `bindDraft`.

Точка входа `/client` экспортирует тело плагина (`apply`/`inject`), `CommandUiRuntime`, классы каталога и попапа с их типами состояния и фиксированные типы контракта; сам компонент оболочки внутренен для регистрации оверлея.

## Model Experience

Косвенно, через хостовый RPC `command.execute`, который запускают пути диспетчеризации и `claim.submit` этого пакета: обработчик совпавшей команды мутирует доменное состояние хоста, которое другие пакеты проецируют в следующий запрос (обработчик `/plan` переключает режим плана, чей владеющий пакет внедряет секцию системного промпта `plan:policy`), тогда как сама командная строка, отсоединённый результат и всякий рендеринг меню/уведомлений остаются на клиенте и никогда не входят в журнал сессии.

#### KV Cache effect

Напрямую никакого; этот пакет ни собирает, ни отправляет запрос провайдеру. Командные обработчики, которые он запускает, могут изменить то, что владеющие хостовые пакеты вносят в системный промпт следующего запроса (появившаяся или исчезнувшая секция заменяет более ранние токены запроса и инвалидирует префикс провайдера с той точки), но этим эффектом владеет и документирует его хостовый пакет каждой команды.

## Известные ограничения и отложенная работа

- **Уведомления об отсоединённых результатах вне сессии откатываются к консоли** — пути fire-and-forget направляют результаты в композер инициировавшей сессии через `SessionInput.notify`; после разборки сессии консольная строка остаётся единственной оставшейся поверхностью.
