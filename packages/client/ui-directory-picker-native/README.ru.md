# @deepseek-ai/dsh-client-ui-directory-picker-native

[English](README.md) | [中文](README.zh.md) | Русский

Нативная поверхность выбора каталога: браузерная половина нативного взаимодействия выбора. Она заполняет два слота каталогового потока в ui-workspace (`conversation.hero.workspace.directoryFlow` и `sidebar.workspaces.directoryFlow`) заполнителем без рендеринга, который отвечает на каждый запрос `open` тем, что вызывает через `ctx.workspaces.pickDirectory()` диалог выбора ОС локального Host, и затем сообщает ровно один исход — выбранный путь, отмену либо сбой — обратно в разговор, которому принадлежит запрос. Сам диалог ОС принадлежит [`dsh-host-directory-picker-native`](../../host/directory-picker-native/README.md); монтаж этого пакета компонует поверхность вместе с тем бэкендом из одной строки cordis.yml, так что клиентскому коду не приходится ветвиться по виду возможности.

Обе регистрации устанавливаются одним транзакционным эффектом через вложенные вызовы `slots.inject()`, поскольку любой из объявляющих входов может активироваться позже или заменить собственное объявление. Заполнитель взводится однократно на каждый восходящий фронт `open`, поэтому повторные рендеры — включая принятие состояния, сохраняющее `open` истинным при активном `busy`, — никогда не запускают второй диалог, а отзыв владельцем `open` взводит следующий запрос заново. Итог доставляется через ref, поэтому ответ достигает новейших обработчиков владельца, а не тех, что были захвачены при открытии диалога. Размонтирование (HMR, заменяющая заполнитель) отбрасывает итог целиком: протокол не несёт отмены на отдельный запрос, поэтому хостовая сторона диалога дожидается ответа, сам ответ никуда не попадает, а заменивший экземпляр взводится заново под всё ещё открытым запросом владельца.

Node-половина — пустой `apply`: она существует, чтобы плагин появлялся в хостовом cordis.yml и Loader, тогда как браузерная половина поставляется через `exports["./client"]` и обнаруживается по декларации манифеста `dsh.client`.

## Model Experience

Нет: выбор каталога — часть интерфейса браузера, и ничто из этого не достигает запроса к модели.

#### KV Cache effect

Нет; этот пакет не собирает и не отправляет запрос провайдеру.

## Known Limitations and Deferred Work

- **Отмены открытого диалога нет** — протокол не имеет отмены на отдельный запрос, поэтому диалог, уже показанный на дисплее хоста, нельзя закрыть из браузера; отброшенный итог просто игнорируется.
- **Только носители локального Host** — диалог ОС открывается на машине, где исполняется Host, поэтому развёртывания с внутрипроцессным и удалённым браузером требуют вместо этого композиции `-browse`. Сбои платформы всплывают через повторяемый диалог папок владельца.
