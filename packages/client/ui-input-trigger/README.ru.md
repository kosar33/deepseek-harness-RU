# @deepseek-ai/dsh-client-ui-input-trigger

[English](README.md) | [中文](README.zh.md) | Русский

Плагин конвейера триггеров ввода: обнаружение `/` и `@` под кареткой (границы слов + правила ярусов предохранителей), группированное меню кандидатов и маршрутизация выбора к зарегистрированным источникам. `ctx.inputTriggers` владеет реестром источников и разрешает один `InputTriggerController` на область сессии (`sessionOf`); монтажный слой беседы приводит в действие `track`/`arbitrate`/`onSpace`/`adjudicate` контроллера. Тот же контроллер раскрывает `toggleSource`, чтобы лаунчер хрома открывал ровно один зарегистрированный источник поверх синтетического диапазона выделения; полученные кандидаты по-прежнему используют обычное меню, клавиатурный арбитраж, колбэк выбора и ограниченные областью мутации ввода. Источники получают проекцию `ClientSessionContext` при каждом вызове — сессии всегда опираются на агента, поэтому проекция состоит из одной лишь идентичности сессии. Источник прогревается в каждом достижимом для него контроллере сессии: реестр, присутствующий при рождении области, греется во время построения контроллера, а источник, зарегистрированный позже, прогревается в каждый живой контроллер самой регистрацией. Источники, чьё содержимое `lexicon` меняется после прогрева, реализуют `subscribeLexicon(session, listener)`; контроллер переспрашивает при каждом уведомлении и публикует агрегацию через своё snapshot-хранилище `lexicon`. Конвейер не знает о командах: арбитраж пробела/enter опрашивает необязательные перехватчики `matchSpace`/`matchEnter` в порядке регистрации, и побеждает первый ответ, не равный undefined. Арбитраж enter также несёт `SubmitEnvelope` (число вложенных изображений композера), чтобы источник мог отклонить отправку, которую не способен потребить целиком; `CommandClaim` декларирует `images: true`, когда его команда принимает изображения композера, и тогда его `submit` получает сериализованные полезные нагрузки третьим аргументом.

Расслоение: `src/core/` — чистое ядро: `detectTrigger`, `menuReduce`/`seedGroups`/`MENU_CLOSED`, `exactMatch`, совсем без React/DOM/cordis; `src/client/service.ts` — оболочка, подключающая ядро к snapshot-хранилищу меню, к выборке кандидатов по каждому попаданию (с фильтром поколений, вытесняемым `AbortSignal`; отказавшие источники исчезают молча с записью в консоль) и к трём путям выбора. `ReferenceInsert.appearance` опционально помечает отображение как `session`, `file` или `folder`, не меняя сериализованного `ref`; глиф и цвет принадлежат потребляющему композеру. `src/types.ts` и два файла `contract.ts` — замороженный межпакетный контракт; изменения требуют арбитража основного потока.

MenuView рендерит хранилище меню в slot `conversation.input.overlay` (вид списка, область сессии) и рендерит null, пока меню закрыто. Вводимые вручную триггеры засеивают каждый источник, зарегистрированный для этого триггера; программный лаунчер засеивает только запрошенный источник и публикует имя источника через snapshot-хранилище `launcher` контроллера, пока меню не закроется либо не возобновится сопровождение набора текста. Группы сортируются по необязательному `InputTriggerSource.order` (меньшие раньше, по умолчанию 0, при равенстве сохраняется порядок регистрации) под строками заголовков, локализуемыми через пространство имён локали `inputTriggers.menu` (неизвестный источник показывает своё исходное имя). Опция `showGroupTitle: false` подавляет эту строку в состояниях ожидания и готовности, а готовая группа, чьи кандидаты объявляют разделы, использует строки разделов вместо заголовка источника. Высота списка зажимается пространством над композером, а нажатие указателя вне меню и окружающей карточки композера его закрывает. Slot принадлежит входу композера ui-conversation (якорь, объявление children, жизненный цикл); его слияние типов SlotMap живёт в `src/client/slots.ts` этого пакета, потому что направление зависимости (ui-conversation → ui-input-trigger) не допускает обратного импорта типов. Шаблон combobox: фокус остаётся в textarea, строки выбираются на mousedown, подсветка следует за `aria-activedescendant`.

Экспорты `/client` — тело плагина (`apply`/`inject`), `InputTriggerService`, `MenuViewInjected` и контрактные типы. Сам MenuView внутренний — регистрация slot замыкается на него.

## Model Experience

Отсутствует: конвейер триггеров — только браузерная презентация; выборы порождают данные `CommandClaim`/`ReferenceInsert`, чьи видимые модели последствия (исполнение команды хостом; вставленный текст ссылки, следующий вместе с обычным промптом) принадлежат потребляющим пакетам хоста и машины ввода.

#### KV Cache effect

Отсутствует: этот пакет ни собирает, ни отправляет запрос провайдера.

## Known Limitations and Deferred Work

- **Только глобальный слой источников** — регистрация источников с областью сессии (затенение по сессии, подобие ScopedLayers) спроектирована, но не включена; реестр задач отслеживает условие-триггер (реальная потребность в источнике на сессию).
- **`InputTriggerCandidate.icon` рендерится текстом** — MenuView опускает строку в иконковый slot дословно; подключение к перечислению иконок дизайн-системы (пятивариантное семейство iconFile) состоится, когда это перечисление выйдет.
- **Дом слияния SlotMap оверлея отделён от владения slot** — единственное слияние `conversation.input.overlay` живёт здесь, тогда как якорем, объявлением children и жизненным циклом владеет ui-conversation, потому что направление зависимости — ui-conversation → ui-input-trigger.
