# @deepseek-ai/dsh-client-ui-layout

[English](README.md) | [中文](README.zh.md) | Русский

Плагин оболочки: трёхколоночный AppFrame (ручки перетаскивания и цепочка уступок) плюс сервис геометрии панелей `ctx.layout`; он регистрируется в принадлежащем рантайму slot'е `root` и объявляет `sidebar`, `conversation`, `details` и `conversation.empty`. Граница изменения ширины сайдбара — невидимая зона захвата, тогда как граница details сохраняет свою плавающую пилюлю; во время уступки сжимается только details, который затем закрывается сам. Закрытый сайдбар удерживает 56-пиксельную рейку управления, а details закрывается до нулевой ширины. Пакет также усаживает презентера темы: тот использует разрешённые снапшоты `ctx.theme` и проецирует их на документ (`html { color-scheme }` для нативной рамки браузера, `body[data-ds-dark-theme]` по активной цветовой схеме, алиасные токены темы как инлайн-переменные на body и один принадлежащий пакету `<meta name="theme-color">`, чьё содержимое следует за вычисленным фоном body). Измерение после применения палитры и токенов сохраняет за отрисованным фоном роль единственного авторитета в цвете; освобождение ресурсов презентера удаляет его узел метаданных вместе с прочими глобальными записями.

AppFrame всегда монтирует колонки conversation и details; подключённый Session отрисовывается через `SessionProvider`. Временное хранилище раскладки стартует со сайдбаром шириной по умолчанию и закрытым details и никогда не читает и не пишет `localStorage`. Hero и прочие невыбранные состояния тоже выводят нулевую отображаемую ширину details, не меняя это сохранённое предпочтение. AppFrame удерживает последний непустой id Session между этими состояниями: первый Session остаётся закрытым, явное действие над details открывает заданную контрактом ширину по умолчанию, возврат к тому же Session восстанавливает его неизменную ширину, а выбор другого Session закрывает details до отрисовки. Owner-доля conversation пуста, тогда как owner-доля sidebar содержит только `collapsed` и `width`; регистранты получают бизнес-данные из стандартных хуков, а действия — из собственных inject-срезов.

Экспорты `/client` — тело плагина (`apply`/`inject`), `LayoutController` и четыре интерфейса owner-доли. AppFrame, хранилище панелей и решатель уступок остаются внутренними для пакета.

## Model Experience

Отсутствует: оболочка раскладки управляет состоянием просмотра в браузере; ничто из этого пакета не попадает в запрос к модели.

#### KV Cache effect

Отсутствует; этот пакет не собирает и не отправляет запрос к провайдеру.

## Известные ограничения и отложенная работа

- **Геометрия панелей временна** — перезагрузка восстанавливает сайдбар по умолчанию и закрытый details; переключение между разными id Session также закрывает details и забывает его перетащенную ширину, тогда как невыбранные поверхности отрисовывают details нулевой ширины, не меняя геометрию.
- **Автозакрытие по цепочке уступок выводит нулевую ширину, не трогая предпочитаемую** — панель сама восстанавливается, когда окно расширяется; использующий код не должен читать сохранённую ширину details как отображаемую истину.
- **Якорение прокрутки при переформатировании во время сжатия отсутствует** — изменения раскладки могут сместить окно просмотра читателя.
