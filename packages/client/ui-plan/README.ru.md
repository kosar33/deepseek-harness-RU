# @deepseek-ai/dsh-client-ui-plan

[English](README.md) | [中文](README.zh.md) | Русский

Статусный чип режима плана — чисто браузерный плагин поверхности. Браузерная половина занимает единственное место `conversation.input.plan`, объявленное в conversation (справа от переключателя режима доступа); узловая половина — пустой apply (строка ростера). Само поведение плана — команда `/plan`, состояние `plan/mode`, фиксируемое на границе хода либо при простое, проекционная единица `plan` и секция политики — принадлежит [`@deepseek-ai/dsh-plan-mode`](../../plan/plan-mode/README.ru.md), компонуемому в ростере хоста независимо.

В режим плана входят через командный путь `/plan`: пользователи выбирают Plan в меню Command композера за знаком `+` или вводят `/plan`; этот пакет не отрисовывает никакого неактивного управления планом. Пока действующая цель вычисляемой хостом проекции `plan` — режим плана (`pending ? !active : active` — свёрнутое значение хоста, а не клиентский оптимизм, поэтому приходящий кадр исправляет чип в любую сторону), место отрисовывает статусную кнопку «Plan ×» в предупреждающем цвете, которая исполняет `/plan off` через `command.execute`; иначе место остаётся пустым — хост без режима плана (или Draft без сессии) не показывает ничего. Пока действующая цель — режим плана, placeholder текстового поля композера сменяется подсказкой задачи плана — «describe your task to generate plan», локализованной через пространство имён `conversation` ui-conversation (ключи `placeholder.plan` / `hint.plan`) и дословно общей с заявленной подсказкой команды `/plan` (её рендерит композер из той же проекции; владельческие placeholder'ы имеют приоритет).

Чип несёт доступное описание «Plan mode on, press to turn off». Отказы допуска (`matched: false`, бизнес-ошибки, транспортные сбои) проявляются встроенной ошибкой, и чип остаётся, пока проекция не подтвердит выход.

Модель выходит из режима плана через стабильный инструмент `exit_plan_mode`; его рецензирование плана использует компонуемый веб-канал вопросов.

## Model Experience

Опосредованно — через командную строку `/plan off`, которую отправляет чип: `@deepseek-ai/dsh-plan-mode` владеет видимой модели секцией политики, схемой инструмента выхода и журналируемым состоянием, которым управляет эта строка, тогда как этот пакет лишь отрисовывает проекцию и отправляет то, что пользователь мог бы с тем же успехом набрать сам.

#### KV Cache effect

Вход в режим плана и выход из него меняют активную секцию системного промпта `plan:policy`, а значит, и префикс запроса; сам чип не добавляет в промпт никакого содержимого.

## Известные ограничения и отложенная работа

- **Режим плана — руководство, а не песочница исполнения** — развёртывания, которым требуется принудительное планирование с доступом только для чтения, должны компоновать независимые политики песочницы и одобрения.
- **Чип принадлежит композеру по умолчанию** — ожидающее взаимодействие со всем композером, например рецензирование плана, временно заменяет InputBar вместе с его чипом.
- **Неактивного управления планом нет** — вход использует общий источник Command; сессия с возможностью, но неактивным режимом не показывает никаких план-аффордансов в строке инструментов.
