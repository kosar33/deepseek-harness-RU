# `@deepseek-ai/dsh-client-ui-reference`

[English](README.md) | [中文](README.zh.md) | Русский

Единый источник Web для `@file` и `@session`. Для незакавыченного токена браузер одновременно запускает Remote-вызовы `fileReferences/list` и `sessionReferenceResolver/candidates`, детерминированно ставит файлы перед сессиями с зарегистрированными в локали метками папок, файлов и сессий и отрисовывает строки под невыбираемыми заголовками секций файлов и сессий без избыточного сырого названия источника `reference`. Каждый из двух доменов кандидатов деградирует независимо. Открытый токен `@"…` ищет только файлы.

Выбор файлов сохраняет естественный текст, заданный общей грамматикой `@path`, как свою скрытую сериализованную и буферную форму. Файл закрывает автодополнение атомарной встроенной ссылкой, отображаемой глифом файла, именем файла в предметном цвете и без капсулы. Каталог остаётся обычным редактируемым текстом пути с глифом папки и удерживает меню активным на завершающем слэше, чтобы пользователь мог спуститься ещё на уровень. Пути с пробелами используют форму `@"path with spaces"`, и кавычка, открытая пользователем явно, остаётся закавыченной.

Выбор сессии вставляет атомарную встроенную ссылку, чьи скрытый `ref` и представление в буфере обмена — каноническое упоминание `@[label](dsh-session:…)`, возвращаемое Host. Видимая форма — глиф пузыря чата плюс название сессии в предметном цвете, без капсулы; сериализация никогда не восстанавливает идентичность из этого названия. Обычная отправка несёт каноническое упоминание через `session.prompt`; сервис ссылок на сессии валидирует его и захватывает контекст модели на `agent/pre-step`.

Экспорт `/client` — только тело плагина (`apply`/`inject`); кодирование кандидатов остаётся внутренним для эффекта регистрации.

## Model Experience

Опосредованно — через `@deepseek-ai/dsh-file-reference-local` для подсказок по путям и `@deepseek-ai/dsh-session-reference` для подготовленных снапшотов сессий.

#### KV Cache effect

Просмотр кандидатов не действует на модель. Выбранный файл или сессия меняет только суффикс нового пользовательского сообщения и следующий за этим сообщением подготовленный Host'ом контекст ссылки на сессию; более ранняя история цели остаётся неизменной.

## Известные ограничения и отложенная работа

- **Отказ кандидатов намеренно тих** — один недоступный или неудавшийся Remote-вызов обнаружения не даёт строк соответствующего домена. Отказ подготовки ссылки на сессию происходит после принятия промпта и завершает этот ход агента.
- **Сканирования файлов на стороне браузера нет** — веб-дополнение требует смонтированного провайдера Host `ctx.fileReferences`; браузер не может откатиться к собственной файловой системе.
- **Поиск сессий остаётся только по метаданным** — обнаружение фильтрует id сессии, cwd и последний основанный на журнале заголовок через `ctx.sessionReferenceResolver`; тела сообщений и полные транскрипты не прочёсываются.
