# `@deepseek-ai/dsh-client-ui-reference`

[English](README.md) | [中文](README.zh.md) | Русский

Единый источник Web для `@file` и `@session`. Для токена без кавычек браузер одновременно запускает Remote-вызовы `fileReferences/list` и `sessionReferenceResolver/candidates`, детерминированно ставит файлы перед сессиями с зарегистрированными в локали метками папок, файлов и сессий и отрисовывает строки под невыбираемыми заголовками секций файлов и сессий без избыточного сырого названия источника `reference`. Каждый из двух доменов кандидатов деградирует независимо. Открытый токен `@"…` ищет только файлы.

Выбор файлов сохраняет естественный текст, заданный общей грамматикой `@path`, как скрытую сериализованную форму и представление в буфере обмена. Файл закрывает автодополнение атомарной встроенной ссылкой с глифом файла, именем файла в предметном цвете и без капсулы. Каталог остаётся обычным редактируемым текстом пути с глифом папки и удерживает меню активным на завершающем слэше, чтобы пользователь мог спуститься ещё на уровень. Пути с пробелами используют форму `@"path with spaces"`, и кавычка, открытая пользователем явно, остаётся в тексте.

Выбор сессии вставляет атомарную встроенную ссылку, чьи скрытый `ref` и представление в буфере обмена — каноническое упоминание `@[label](dsh-session:…)`, возвращаемое Host. Видимая форма — глиф пузыря чата плюс название сессии в предметном цвете, без капсулы; сериализация никогда не восстанавливает идентичность из этого названия. Обычная отправка несёт каноническое упоминание через `session.prompt`; сервис ссылок на сессии валидирует его и захватывает контекст модели на `agent/pre-step`.

Экспорт `/client` — только тело плагина (`apply`/`inject`); кодирование кандидатов остаётся внутренней деталью эффекта регистрации.

## Model Experience

Опосредованно — через `@deepseek-ai/dsh-file-reference-local` для подсказок по путям и `@deepseek-ai/dsh-session-reference` для подготовленных снапшотов сессий.

#### KV Cache effect

Просмотр кандидатов не влияет на модель. Выбранный файл или сессия меняет только суффикс нового пользовательского сообщения и любой подготовленный Host'ом контекст ссылки на сессию, который следует за этим сообщением; предшествующая история цели остаётся неизменной.

## Известные ограничения и отложенная работа

- **Отказ кандидатов намеренно тих** — один недоступный или неудавшийся Remote-вызов обнаружения не даёт строк соответствующего домена. Сбой при подготовке ссылки на сессию возникает после принятия промпта и завершает этот ход агента.
- **Сканирования файлов на стороне браузера нет** — веб-автодополнению требуется смонтированный провайдер Host `ctx.fileReferences`; браузер не может откатиться на собственную файловую систему.
- **Поиск сессий идёт только по метаданным** — обнаружение фильтрует id сессии, cwd и последний заголовок из журнала через `ctx.sessionReferenceResolver`; тела сообщений и полные транскрипты в поиске не участвуют.
