# @deepseek-ai/dsh-client-ui-renderer

[English](README.md) | [中文](README.zh.md) | Русский

Браузерный плагин Cordis, владеющий слоем рендеринга на React. [`dsh-client-web`](../web/README.md) отрисовывает не привязанную к фреймворку загрузочную страницу и загружает полный реестр клиентских плагинов; после активации каждого входа он вызывает `ctx.uiRenderer.mount(container)`. Этот пакет предоставляет указанный сервис, устанавливает рендерер slots, гидратирует уже созданный загрузочный DOM, переключается на собранное приложение перед следующей отрисовкой и возвращает disposer размонтирования корня React.

Клиентский вход также владеет реализацией на React для outlets слотов, провайдеров сессий и привязки observable-источников к uSES. Бизнес-плагины передают «голые» observable-источники через типизированный compartment `hooks` слота; рендерер привязывает их в outlet. Плагин активируется после `slots`, `sessions` и `layout`, проецирует заголовок выбранной сессии и выполняет единственный на уровне контекста вызов `renderSlot('root')`. React, React DOM, Cordis, ui-slots и ui-primitives сохраняют одну браузерную идентичность благодаря статической таблице модулей веб-оболочки; этот пакет поставляется как динамический клиентский бандл.

## Model Experience

Отсутствует: рендерер UI лишь собирает браузерный интерфейс и не добавляет ничего видимого модели.

#### KV Cache effect

Эффекта нет; этот пакет не собирает и не отправляет запросы к провайдеру.

## Известные ограничения и отложенная работа

- **Первый кадр приложения ожидает каждый клиентский вход** — ядро загрузки передаёт точку монтирования только после того, как стабилизируется весь реестр загрузчика. Готовность отдельных регионов остаётся отложенной.
- **Рендеринг slots не интегрирован с Suspense и не поддерживает ленивую загрузку по входам** — полный реестр плагинов стабилизируется прежде, чем рендерер смонтирует корень.
