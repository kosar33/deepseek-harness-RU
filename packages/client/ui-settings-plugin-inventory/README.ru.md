# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | [中文](README.zh.md) | Русский

Доступная только для чтения вкладка **Список плагинов** в вебовых настройках. Браузерный плагин регистрирует один локализованный вклад `settings.plugins.tab` с id `all`; раздел Plugins владеет элементом навигации и хромом вкладки. Во время активации плагина удалённых чтений не выполняется. Первый выбор вкладки монтирует её и лениво вызывает `ctx.remote.pluginInventory.list()` через [`api-remotes`](../../api/remotes/README.ru.md).

Вкладка отрисовывает поддерживающий поиск двухколоночный каталог компактных раскрывающихся карточек. Свёрнутая карточка использует короткое имя модуля в качестве заголовка и маленькую метку действующего включения; включённые записи также показывают цветную точку состояния корневого fiber'а. Развёртывание карточки открывает id входа дерева Loader без избыточной подписи поля, затем действующую конфигурацию, а для включённых записей — статус Cordis. Выключенные записи опускают избыточное несмонтированное состояние рантайма. Id входа остаётся ключом React, идентичностью раскрытия, значением в деталях и дополнительной целью поиска; он никогда не классифицируется по форме строки. Состояния загрузки, пустого списка, отсутствия совпадений и общей неудачи остаются внутри смонтированного компонента, а неудавшееся чтение можно повторить, не раскрывая транспортных деталей. Регистрация использует `ctx.slots.inject()`, поэтому следует позднему объявлению вкладки, его переобъявлению, сменам локали и разборке, не импортируя владельца раздела.

## Model Experience

Отсутствует: этот пакет лишь визуализирует принадлежащий Host'у снимок развёртывания в браузерных настройках и не регистрирует ничего обращённого к модели.

#### KV Cache effect

Эффекта нет; этот пакет ни собирает, ни отправляет запрос провайдеру.

## Известные ограничения и отложенная работа

- **Один снимок на каждое монтирование настроек или повтор чтения** — вкладка не подписывается на изменения Loader и не перечитывает данные автоматически после переподключения; переключение вкладок сохраняет текущий снимок, а повторное открытие настроек получает новый.
- **Только читающий взгляд на Loader** — локальный поиск не добавляет сведений о происхождении, диагностику активации текущего браузера, группировку по источнику или средства изменения плагинов.
