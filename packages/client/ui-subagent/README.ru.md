# @deepseek-ai/dsh-client-ui-subagent

[English](README.md) | [中文](README.zh.md) | Русский

Владелец веб-фичи субагентов: добавляет навигацию lineage по текущим заголовкам в `conversation.session.header.lineage`, замены «только чтение» с объяснением причины в цепочку композера диалога и существующий источник ссылок `@` в `ctx.inputTriggers`.

Рендерер lineage в шапке читает `subagentsByParent` и сводки сессий через стандартный хук `useSessions`. На обычной сессии он сохраняет текущий заголовок и, когда есть потомки, добавляет `/` плюс выпадающий список счётчика потомков перед строкой действий шапки. Каждый breadcrumb субагента использует шкалу 12px триггера счётчика и соединяет свой заголовок с фиксированным двойным шевроном; текущий breadcrumb сохраняет основной цвет и вес 500, а предки используют третичный цвет и вес 400. Наведение на объединённый элемент управления на 150 мс открывает каталог его непосредственного родителя, ArrowDown остаётся клавиатурным путём входа, а щелчок по предку отменяет ожидающее меню и поднимается вверх, не открывая его. Каждый каталог разрешает переключение между сиблингами и выделяет жирным свою выбранную строку; метка каталога переопределяет заголовок из сводки сессии, и каждый переключатель, чей каталог ещё не загружен, запрашивает его автоматически. Только текущий субагент добавляет собственный выпадающий список счётчика потомков. Длинные заголовки breadcrumb усекаются, при этом шеврон остаётся видимым. Триггер счётчика покрывает полную линию потомков только из субагентов, останавливается на обычных fork'ах и показывает идущую активность, когда любой из посчитанных потомков выполняется. Компактное дерево остаётся авторитетным по прямому каталогу: строки продолжаемых и one-shot детей показывают режим плюс активность `running`/`inactive` и необязательный заголовок из журнала, а замыкающая колонка ставит суммарный долговечный расход провайдера над длительностью активного хода. Суммы токенов складывают четыре непересекающихся сегмента `tokenUsage`. Визуальная длительность остаётся точной до секунды ниже суток, затем использует не более двух смежных единиц — дней/часов, приблизительных месяцев/дней или приблизительных лет/месяцев, — тогда как наведение и доступимое имя сохраняют точное значение дни/часы/минуты/секунды. Длительность суммирует завершённые ходы `subagentTiming`, продвигается раз в секунду только для открытого хода выполняющегося ребёнка и замирает после того, как ребёнок стал неактивным; прерванный открытый ход ограничен его же срезом `active.through`, но не более новой метаданной сессии. Строка one-shot без метки откатывается к своему id сессии, а повреждённые, неподдерживаемые или недоступные строки остаются читаемыми, но отключёнными. Подсказка `hasChildren` каждой здоровой строки определяет раскрытие до взаимодействия, поэтому известные листья никогда не показывают стрелку; уровень каталога резервирует колонку раскрытия, только когда хотя бы одна здоровая строка — ветвь, что позволяет уровням без ветвей начинаться с ведущего маркера статуса. Разворачивание ветви немедленно резервирует по одной отключённой строке загрузки на каждого известного непосредственного потомка, затем лениво заменяет их авторитетным каталогом этого ребёнка. Каждая видимая ветвь сообщается рантайму, чтобы кадры состава вызывали дебаунсированное обновление только там, где дерево потребляется. Выбор любой глубины вызывает `SessionRuntime.openSubagent()` с точным адресом строки `{parentSessionId, childSessionId, mode}`. Локальное состояние компонента владеет видимостью дерева, развёрнутыми ветвями, фокусом клавиатуры и часами идущей длительности. ArrowRight/ArrowLeft разворачивают и сворачивают ветви; ArrowUp/ArrowDown, Home, End и Escape перемещаются или закрывают дерево; закрытие возвращает фокус триггеру. Оформление использует только токены.

Ребёнок one-shot всегда избирает композер «только чтение», который представляет транскрипт как запись завершённого выполнения. Продолжаемый ребёнок делает так, только когда его точный родитель недоступен и ребёнок не выполняется, с текстом, объясняющим путь восстановления; пока такой ребёнок ещё выполняется, селектор уступает обычному композеру, чей ввод и действие Send отключены, но независимый Stop остаётся пригодным, и захват возвращается, когда ребёнок останавливается. Продолжаемый ребёнок с живым родителем сохраняет обычное входное обрамление, чья Session маршрутизирует промпты через `subagent.prompt`: ввод и Send остаются доступны, пока ребёнок выполняется, потому что каждое продолжение встаёт в FIFO-inbox ребёнка, а независимый Stop маршрутизируется через `subagent.interrupt`. Этот пакет никогда не получает контекст хоста и не вызывает обращённых к модели инструментов. Поведение каталога и композера определено [Agent Note о веб-диалогах субагентов](../../../.agents/notes/implemented/feature/2026-07-27-web-subagent-conversations.md) и [Agent Note о прерывании текущего хода](../../../.agents/notes/implemented/feature/2026-08-06-continuable-subagent-interrupt.md).

Строки Session субагентского происхождения опущены в обычной боковой панели, поэтому каталог в шапке родителя — их точка входа для навигации. Обычные fork'и остаются в боковой панели.

Источник `@` остаётся сознательно отдельным и инертным. Кандидаты — выполняющиеся дети без RPC из `ctx.sessions.list`; выбор одного вставляет литеральный текст `@label `, а кодек проецирует `@label`. У него нет перехватчиков арбитража команд, и он не разрешает метки в адреса продолжений.

## Model Experience

### Текст метки субагента в пользовательском промпте

#### What the model sees

На вход модели влияет только legacy-источник ссылок `@`: выбранный кандидат попадает в обычное пользовательское сообщение как литеральный `@label`, без выделенного блока или разрешения на стороне хоста. Просмотр каталога, навигация по детям и просмотр персистентного транскрипта не добавляют секции промпта; принятое содержимое продолжения становится обычным FIFO-пользовательским сообщением через хостовый адаптер субагентов.

#### Token effect

Условно и append-only: литеральный `@label` или человеческое продолжение добавляет токены только в своё новое пользовательское сообщение. Операции каталога и транскрипта добавляют ноль токенов модели.

#### KV Cache effect

Append-only. Этот пакет никогда не правит более ранние токены запроса.

## Известные ограничения и отложенная работа

- **У каталога нет долговечного исхода** — активность и тайминги не различают завершение, сбой или отмену, и UI не предоставляет идентичности Activation; остановка ограничена Stop'ом текущего хода композера для выполняющегося продолжаемого ребёнка.
- **Ссылки `@` остаются текстом отображаемого заголовка** — дубликаты или переименованные метки неоднозначны, поэтому они намеренно не приобретают семантики продолжений.
