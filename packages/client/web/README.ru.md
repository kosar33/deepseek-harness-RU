# @deepseek-ai/dsh-client-web

[English](README.md) | [中文](README.zh.md) | Русский

Ядро веб-загрузки: `new AppWebEntry(el, seams?).run()` монтирует клиент в два этапа. Этап модулей вызывает установленный Host'ом `window.__ModuleLoader__.create()` с `window.__DSH_BOOT__`, статическими модулями оболочки и любым тестовым переопределением транспорта; фасад после принятия регистраций, предзагруженных парсером, возвращает собранную систему модулей и разобранный манифест. Затем пакет выполняет предзагрузку яруса `immediately`. Этап плагинов монтирует вендоренный Cordis Loader, внедряет эту систему модулей через интерфейс `internal` загрузчика, единообразно создаёт каждую запись графа и ждёт, пока каждый fiber станет ACTIVE. После этого он передаёт размеченный загрузочный DOM операции `ctx.uiRenderer.mount(el)` динамического UI-рендерера; рендерер гидратирует этот DOM, прежде чем переключиться на полный интерфейс. Host владеет графом, предзагрузками парсера и фасадом; AppWebEntry не знает id пакета начальной загрузки и не разбирает формат протокола.

Загрузочная страница использует чистый DOM и локальный CSS, поэтому сбои клиентских бандлов и активации плагинов остаются видимыми. Её резервные шрифты и цвета совпадают с токенами темы, приходящими во время загрузки. Обновления fiber удерживают один узел спиннера и наращивают его CSS-дугу по мере первого перехода записей в активное состояние; гидратация сохраняет этот узел и фазу его анимации до коммита приложения. Монтирование React, отрисовка slot'ов, сборка приложения и проекция заголовка окна браузера живут в [`ui-renderer`](../ui-renderer/README.md). Бандл модулей кэширует свои материализованные экспорты и предоставляет захваченную в замыкании систему, когда его обычная запись графа активируется; ожидание сервисов Cordis делает порядок создания строк графа независимым от той активации.

`PLATFORM_MODULES` (src/platform.ts) — единственный источник истины для разделяемых модулей, засеиваемых оболочкой. Вместе с `PRELOADED_CLIENT_EXTERNALS` он определяет неявную внешнюю базовую линию для каждого динамического бандла; `dsh.client.external` добавляет лишь точечные запросы вне базовой линии.

Необязательный параметр переопределения `seams` пробрасывает транспортное переопределение `loadBundle` системы модулей (`BootSeams`) для окружений, где исполнение внешнего `<script>` не может добраться до контекста страницы; обычные браузерные вызывающие опускают его. Приоритетнее него по умолчанию стоит заранее внедрённый транспорт страницы: когда `globalThis.__DSH_TRANSPORT__` (`ClientTransportHooks` пакета connection) несёт `loadBundle`, этап модулей принимает его как транспорт бандлов и пропускает HTTP-предзагрузку яруса immediate — явный `seams` всё же побеждает.

## Model Experience

Отсутствует: входная оболочка загружает дерево плагинов браузера; ничто из этого пакета не попадает в запрос к модели.

#### KV Cache effect

Отсутствует; этот пакет не собирает и не отправляет запрос к провайдеру.

## Известные ограничения и отложенная работа

- **Приложение ждёт полный ростер** — одна неудавшаяся запись сохраняет видимой свободной от фреймворков загрузочную страницу с отчётом по каждой записи; частичная доступность интерфейса не поддерживается.
