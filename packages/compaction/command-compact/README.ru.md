# @deepseek-ai/dsh-command-compact

[English](README.md) | [中文](README.zh.md) | Русский

Обращённая к человеку команда `/compact` поверх [`ctx.compaction`](../compaction/README.ru.md). Плагин регистрирует одну глобальную команду через [`ctx.commands`](../../interaction/commands/README.ru.md), поэтому любой собранный командный адаптер находит и выполняет её без хода модели. Решениями о допуске, блокировке и долговечности владеет [Agent Note о поставленной в очередь ручной компакции](../../../.agents/notes/implemented/feature/2026-07-30-queued-manual-compaction.md).

## Контракт команды

| Ввод | Результат |
|---|---|
| `/compact` | Суммирует один полезный сбалансированный старый участок даже ниже автоматического давления, затем сообщает число заменённых записей истории и оценку токенов после того, как отдельная скобка сброшена. |
| `/compact` при отсутствии поддающейся компакции истории | `No compactable history yet.` — ни маркер, ни мутация поверхности не записываются. |
| `/compact <anything>` | `Usage: /compact (no arguments)` — команда не принимает аргументов и не вызывает бэкенд компакции. |

Команда не зависит от бэкенда: она зависит только от `compactNow(agent, signal)`. Вызывающий агент — точная цель, а сигнал отмены диспетчеризующего UI пробрасывается через seam. Каждый состоявшийся вызов записывает принадлежащую исполнителю пару `command/run` / `command/done`, живущую только в журнале; ни одно из этих событий не попадает в историю модели. При успехе `command/done.sourceEventSeq` называет событие `compaction/summary` транзакции, чтобы презентация могла свернуть жизненный цикл команды в её чекпоинт, не разбирая текст результата и не предполагая соседних строк.

Ожидаемые коды `ManualCompactionError` становятся стабильными прямыми ошибками:

| Код | Прямой результат |
|---|---|
| `busy` | `Compaction is unavailable because this process has an active compaction, or the agent is not idle.` |
| `changed` | `The history selected for compaction changed before it could be replaced. The conversation is unchanged; the attempt is recorded in the session log.` |
| `summary` | `Compaction could not produce a useful summary. The conversation is unchanged; the attempt is recorded in the session log.` |
| `commit` | `Compaction did not finish cleanly; some session history may have changed. Inspect the current session state before retrying.` |
| `persistence` | `Compaction finished, but the session could not be saved.` |

Результат busy намеренно ограничен процессом: живая непарная отметка блокирует, тогда как отметка старше новейшего `session/end-seed` устарела и не блокирует. Неожиданные отказы реализации отклоняют диспетчеризацию. Отмена остаётся авторитетной: бэкенд завершает требуемую зачистку close/flush, а команда внутренне завершается как `Compaction cancelled.`, пока исполнитель команд прекращает ожидание со своей ошибкой отмены. Освобождение ресурсов плагина сначала дерегистрирует `/compact`, затем дожидается каждого уже начатого обработчика, поэтому разборка корня не может пересечь границу close или flush прерванной команды.

Промпты, поданные во время идущей компакции, остаются принятыми в обычной FIFO агента с теми же фактами идентичности и пробуждения. Они стартуют только после явного чекпоинта долговечности компакции и освобождения допуска. Внедрённый в простое контекст не удерживается: он может попасть в журнал между `compaction/start` и `compaction/end`, а позиционная замена оставляет его видимым после чекпоинта.

## Композиция

Продюсер внедряет `commands` и `compact`. Смонтируйте реестр команд, один бэкенд и этот плагин:

```yaml
- id: commands
  name: '@deepseek-ai/dsh-commands'
- id: compaction-basic
  name: '@deepseek-ai/dsh-compaction-basic'
- id: command-compact
  name: '@deepseek-ai/dsh-command-compact'
```

Поставляемая база `dsh` монтирует его рядом с `compaction-basic`, а веб-клиент предоставляет командный адаптер. Автоматизационные поверхности, не собирающие командного адаптера, сохраняют только автоматическую компакцию.

## Model Experience

### Человеческое управление `/compact`

#### What the model sees

Слэш-ввод и прямой результат никогда не попадают в запрос к модели. Принятая компакция отдельно заменяет старый участок чекпоинтом роли пользователя от бэкенда внутри обособленной скобки `compaction/* { turn: null }`.

#### Token effect

Жизненный цикл команды не добавляет модельных токенов. Успешная компакция сокращает последующие запросы, заменяя выбранный участок одним обрамлённым итогом; суммаризация сама является одним вспомогательным запросом.

#### KV Cache effect

Обнаружение и учёт командных вызовов на кэш не влияют. Принятая замена поверхности делает переиспользование недействительным начиная с первого затенённого токена истории.

## Известные ограничения и отложенная работа

- **Только в простое** — `/compact` сообщает `busy`, когда ход или уже принятый пробуждающий промпт имеет приоритет; сама команда в очередь не ставится.
- **Без аргументов диапазона или политики** — форма без аргументов держит поведение стабильным между командными адаптерами. Явные диапазоны остаются программным путём `compactRegion()`.
- **Только командные адаптеры** — поверхности без `ctx.commands` не могут его вызвать и полагаются на автоматическую компакцию по давлению.
