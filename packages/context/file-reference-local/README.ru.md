# `@deepseek-ai/dsh-file-reference-local`

[English](README.md) | [中文](README.zh.md) | Русский

Реализация `ctx.fileReferences` на локальной файловой системе. Она поддерживает один ограниченный `WorkspaceFileSearch` на агента, укоренённый в `cwd` этой сессии с откатом к cwd хостового процесса. Индекс ранжирует прямые перечни каталогов для запросов, содержащих `/`, иначе нечётко ранжирует ограниченный рекурсивный индекс; каталоговые символические ссылки он никогда не проходит.

События результатов инструментов инвалидируют переиспользуемый индекс адресованного агента, чтобы последующее автодополнение наблюдало вероятные мутации рабочей области. Освобождение ресурсов агента высвобождает этот индекс и его ограниченный скоупом вклад в промпт; освобождение ресурсов плагина дожидается каждого промптного fiber'а и высвобождает все кэшированные поиски.

## Конфигурация

| Ключ | По умолчанию | Контракт |
|---|---:|---|
| `maxResults` | `20` | Максимум ранжированных кандидатов, возвращаемых на один запрос. |
| `maxEntries` | `10000` | Максимум файлов и каталогов, индексируемых в рабочей области одного агента. |
| `excludedDirectories` | `[".git", "node_modules"]` | Базовые имена каталогов, исключаемые из обхода и из кандидатов. |

Каждое числовое значение ДОЛЖНО быть положительным безопасным целым числом (safe integer). Исключаемые имена ДОЛЖНЫ быть непустыми базовыми именами без `/` или `\`.

## Model Experience

### Руководство по файловым ссылкам, когда доступен `read`

#### Что видит модель

Когда у адресованного агента есть действующий инструмент `read`, провайдер добавляет этот стабильный раздел системного промпта:

##### Инструкция по файловым ссылкам

```markdown
Paths prefixed with @ are files explicitly referenced by the user. Use the read tool when their contents are needed; do not claim to have inspected a file before reading it.
```

#### Эффект на токены

Условный и фиксированный: единственное предложение присутствует, пока `read` виден адресованному агенту; поиск кандидатов сам не добавляет токенов, а выбранный путь добавляет лишь свои обычные символы пользовательского сообщения.

#### KV Cache effect

Стабильное предложение входит в префикс системного промпта. Монтирование или удаление этого провайдера, равно как изменение видимости `read`, меняет этот префикс; запросы, кандидаты и инвалидации индекса — нет.

## Известные ограничения и отложенная работа

- **Пространство имён локально для хоста** — провайдер сканирует файловую систему хоста Harness, поэтому удалённым или виртуальным реализациям `read` нужен провайдер, чьё пространство имён совпадает с инструментом.
- **Ограниченный рекомендательный индекс** — очень большие рабочие области могут опускать пути сверх `maxEntries`, а исключённые или нечитаемые каталоги не появляются вовсе.
- **Нет семантики ignore-файлов** — `.gitignore` и прочие ignore-файлы проектов не влияют на обнаружение; исключаются только настроенные базовые имена каталогов.
