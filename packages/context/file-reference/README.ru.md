# `@deepseek-ai/dsh-file-reference`

[English](README.md) | [中文](README.zh.md) | Русский

Seam обнаружения файловых ссылок и безопасная для браузера грамматика `@file`, разделяемые пользовательскими интерфейсами с опорой на хост. `ctx.fileReferences.list(agent, query, signal)` возвращает для адресованного агента кандидатов — файлы или каталоги — только путями; конкретные провайдеры владеют доступом к пространству имён, ранжированием, кэшированием и инвалидацией. Тот же контракт удалённо вызывается как унарный метод Remote `fileReferences/list` (`@Remote` на Service Definition, отмена через зарезервированный завершающий сигнал), поэтому браузерные потребители вызывают `ctx.remote.fileReferences.list` без маршрута API Proxy.

`activeAtToken()` распознаёт токен `@path` или незакрытый токен вида `@"path with spaces` только в начале ввода или после пробельного символа, поэтому похожий на адрес электронной почты текст не открывает автодополнение. `formatFileMention()` выдаёт соответствующее промпту написание, добавляет `/` к кандидатам-каталогам, сохраняет явно открытую кавычку и отвергает управляющие символы или вложенные кавычки, которые грамматика редактора не способна безопасно представить.

Выбор кандидата не читает и не прикрепляет содержимое файлов. Экспортируемый `FILE_REFERENCE_PROMPT` — стабильное руководство, которое провайдер может установить, когда адресованный агент умеет вызывать `read`.

## Model Experience

Косвенно — через `@deepseek-ai/dsh-file-reference-local`, который условно добавляет стабильное руководство этого пакета по файловым ссылкам.

#### KV Cache effect

Интерфейс и грамматика сами по себе не добавляют токенов запроса; принадлежащий провайдеру раздел промпта определяет поведение кэша.

## Известные ограничения и отложенная работа

- **Кандидаты путей носят рекомендательный характер** — seam не доказывает, что обращённый к модели файловый инструмент, вызванный позднее, сможет обратиться к тому же пространству имён; развёртывания обязаны согласовывать провайдера с фактической реализацией `read`.
- **Нет объекта-ссылки на содержимое файла** — выбранные файлы остаются обычным текстом промпта и требуют явного вызова инструмента моделью, прежде их содержимое станет видимым модели.
