# core/ — стержень продуктового API

[English](README.md) | [中文](README.zh.md) | Русский

Журнал событий сессии, сборка системного промпта, реестр инструментов, словарь агента, выбор модели по умолчанию на уровне развёртывания и конкретный цикл — то, что образует дефолтный управляющий стержень harness'а. Это **продуктовые** пакеты — стабильная поверхность, на которую опираются плагины и потребители.

| Package | Role | ctx key |
|---|---|---|
| [`scope/`](scope/README.ru.md) | Примитив регистрации скоупированного контекста | библиотека — без ключа ctx |
| [`session/`](session/README.ru.md) | Event-sourced журнал событий сессии и хранилище в памяти | `ctx.sessions` |
| [`system-prompt/`](system-prompt/README.ru.md) | Реестр сборки промпта и схем инструментов | `ctx.systemPrompt` |
| [`tools/`](tools/README.ru.md) | Скоупированный реестр инструментов и пайплайн исполнения | `ctx.tools` |
| [`agent/`](agent/README.ru.md) | Интерфейс агента, реестр и словарь событий | `ctx.agents` |
| [`agent-default-model/`](agent-default-model/README.ru.md) | Выбор модели по умолчанию, разделяемый точками входа Agent | `ctx.agentDefaultModel` |
| [`agent-loop/`](agent-loop/README.ru.md) | Дефолтный конкретный драйвер агента | `ctx.agentLoop` |

`scope` поставляет общий примитив скоупинга. `agent` владеет публичным контрактом, а `agent-loop` — его дефолтной реализацией; плагины расширений зависят от seam, благодаря чему драйвер остаётся заменяемым. `agent-default-model` владеет выбором на уровне развёртывания, который точка входа Agent использует, только когда у самой сессии выбора нет.

Запускаемые композиции принадлежат [`examples/agent-spine-demo`](../examples/agent-spine-demo/README.ru.md); эта группа владеет только заменяемыми частями стержня.

Справочник подсистемы — карта цикла по пакетам, дескриптор `Agent` и его контракты доставки/перехвата — находится в [docs/subsystems/core.ru.md](../../docs/subsystems/core.ru.md); дефолтная запускаемая композиция — [`examples/agent-spine-demo`](../examples/agent-spine-demo/README.ru.md).
