# @deepseek-ai/dsh-agent-default-model

[English](README.md) | [中文](README.zh.md) | Русский

Дефолт уровня развёртывания, применяемый, когда точка входа создаёт Agent без собственного выбора модели на уровне сессии. `AgentDefaultModelConfig` предоставляет `ctx.agentDefaultModel`; прямые точки входа вроде `dsh --profile headless` и точки входа на базе Host, такие как ApiProxy, читают один и тот же сервис вместо того, чтобы держать параллельные дефолты провайдера/модели.

Конфигурация плагина требует `{ provider, model }`. Эта запись композиции — основа раздела Settings `agent-default-model`; смонтированный провайдер настроек накладывает выбор пользователя поверх неё, а изменения становятся видны при следующем чтении `currentSelection()`. `reasoningEffort` принадлежит разделу Settings, но намеренно не конфигурации плагина: полный сохранённый выбор способен сбросить effort, когда следующая выбранная модель его не имеет, тогда как значение из композиции унаследовалось бы снова.

- `ctx.agentDefaultModel.currentSelection()` возвращает отсоединённый выбор `{ provider, model, reasoningEffort? }` для вновь созданного Agent.
- `ctx.agentDefaultModel.saveSelection(selection)` сохраняет полный пользовательский выбор. Без провайдера настроек это no-op, и запись композиции остаётся действующей.

Сервис не проверяет принадлежность каталогу. Маршрут провайдера может обслуживать незаявленную модель, а потребитель, реально открывающий запрос к модели, владеет диагностикой доступности.

## Model Experience

Косвенно — через выбор провайдера/модели, передаваемый точке входа; сборка запросов и адаптеры владеют видимым модели запросом.

#### KV Cache effect

Смена дефолта затрагивает только те Agent, которые впоследствии разрешаются на его основе. Существующая сессия, чей журнал запросов уже называет выбор, сохраняет его, поэтому этот сервис не инвалидирует её установившийся префикс.

## Известные ограничения и отложенная работа

- Сервис владеет одним дефолтом на весь процесс; выбор на уровне сессии остаётся ответственностью точки входа.
- Без провайдера настроек `saveSelection()` не может сохранить выбор для последующего Agent.
