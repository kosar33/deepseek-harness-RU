# dsh-agent-tool-presentation

[English](README.md) | [中文](README.zh.md) | Русский

Строка, которой [агентский пресет](../../preset/agent-presets/README.ru.md) сообщает, какую форму своих инструментов видит модель: `native` (все схемы), `code` (только `run_code` плюс сгенерированный TypeScript SDK) или `both`.

## Почему строка, а не реестр

Реестр инструментов не может переехать в пресет. Его потребители целиком относятся к хостовой плоскости — [`dsh-agent-loop`](../agent-loop/README.ru.md) читает его планировщик, [`dsh-apiproxy`](../../host/apiproxy/README.ru.md) читает его презентеров, чтобы отрисовывать карточки инструментов, и каждый плагин инстру регистрируется в нём, — а сервис опускается вниз только вместе со всеми своими потребителями.

Пресет может владеть **представлением** этого реестра. `ctx.tools.presentAs()` объявляет его только для монтируемого агента, поэтому сессия Code Mode работает рядом с нативными в одном процессе, и каждая видит свой каталог. `mode` развёртывания в строке [`dsh-tools`](../tools/README.ru.md) остаётся дефолтом, который получают агенты, не объявившие ничего.

## Что он делает

`native` применяется немедленно. Режим code вместо этого ждёт `ctx.codeRuntime` — сервис хостовой плоскости ([`dsh-code-runtime-worker-thread`](../../code-runtime/code-runtime-worker-thread/README.ru.md)): пресет, выбирающий Code Mode в развёртывании, не собирающем ни одного рантайма, удерживает эту строку в состоянии ожидания, а `dsh-agent-presets` отклоняет монтирование, называя этот id. Альтернатива — оптимистичное применение — перенесла бы неудачу в первый запрос сессии, где оператор не может воздействовать ни на пресет, ни на композицию.

`mode` обязателен, а не задан по умолчанию, потому что пресет без этой строки и так получает дефолт развёртывания; пропущенное значение означало бы, что строка собрана впустую.

Один агент объявляет одно представление. Второе объявление в той же композиции отклоняется, а не сливается: два ответа на вопрос «какую форму видит модель» — это противоречие, а не переопределение.

## Model Experience

Косвенно — через проекцию, которую он выбирает в `dsh-tools`: `code` представляет `run_code` плюс сгенерированный раздел SDK и правило, что напрямую может вызываться только `run_code`; `native` представляет схемы всех инструментов. Выбор также решает, что может ИСПОЛНЯТЬСЯ: при `code` реестр превращает прямой вызов моделью любого другого инструмента в `UNKNOWN_TOOL`, поэтому именно эта строка удерживает объявленную поверхность и вызываемую поверхность одинаковыми для каждого покрываемого ею агента ([заметка о коллапсе исполнителя](../../../.agents/notes/implemented/bug-fix/2026-08-07-code-mode-executor-collapse.md)).

#### KV Cache effect

Прямой инвалидации нет; представление фиксируется при сборке агента, поэтому его префикс запроса стабилен на всю жизнь сессии.

## Известные ограничения и отложенная работа

- **Рантайм остаётся в хостовой плоскости** — пресет может выбрать Code Mode, но не способен поставить нужный ему TypeScript-рантайм; развёртывание, не собирающее ни одного рантайма, не может собрать и code-mode пресет.
