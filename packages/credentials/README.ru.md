# credentials/ — учётные данные и авторизация

[English](README.md) | [中文](README.zh.md) | Русский

Семейство возможностей учётных данных отделяет разрешение ссылки от её провайдера, а оба — от получения учётных данных, которые приходится запрашивать у человека:

| Package | Role | ctx key |
|---|---|---|
| [`credentials/`](credentials/README.ru.md) | Seam ссылок на учётные данные и записей учётных данных | `ctx.credentials` |
| [`credentials-local/`](credentials-local/README.ru.md) | Провайдер переменных окружения и локальных файлов | регистрирует `ctx.credentials` |
| [`authorization/`](authorization/README.ru.md) | Принадлежащие плагинам сценарии получения учётных данных запросом у человека | `ctx.authorization` |

Конфигурация несёт ссылки, а не секретные значения. Потребители разрешают эти ссылки на границе своей операции; семантикой мутации, приоритетов и хранения владеют дочерние README. Сценарий авторизации записывает запись учётных данных и ключуется ею, поэтому два seam встречаются в записи и нигде больше.

Справочник подсистемы — `CredentialRef`, пооперационное разрешение, безопасный для UI `CredentialInfo`, слои провайдеров — находится в [docs/subsystems/credentials.ru.md](../../docs/subsystems/credentials.ru.md).
