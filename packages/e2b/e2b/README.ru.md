# @deepseek-ai/dsh-e2b

[English](README.md) | [中文](README.zh.md) | Русский

Общий владелец жизненного цикла одной песочницы E2B. Адаптеры файловой системы и subprocess внедряют `ctx.e2b`, дожидаются его единственного дескриптора SDK и потому обитают в одном и том же удалённом рабочем дереве Linux и мире процессов. Пакет закрепляет `e2b@2.29.1`; [карта семейства](../README.ru.md) перечисляет подключаемую по выбору композицию.

## Конфигурация

```yaml
- id: e2b
  name: '@deepseek-ai/dsh-e2b'
  config:
    cwd: /home/user/workspace
    timeoutMs: 300000

- id: subprocess-e2b
  name: '@deepseek-ai/dsh-subprocess-e2b'

- id: fs-e2b
  name: '@deepseek-ai/dsh-fs-e2b'
```

`apiKey` необязателен, иначе читается `E2B_API_KEY`; ключ настраивает соединение хостового SDK и никогда не устанавливается внутрь песочницы. `cwd` по умолчанию равен `/home/user/workspace` и **ДОЛЖЕН** быть абсолютным POSIX-путём. `timeoutMs` по умолчанию равен пяти минутам и управляет временем жизни песочницы; истечение срока удаляет её.

## Жизненный цикл и владение

Конструирование запускает одно создание песочницы. Перед разрешением `getSandbox()` сервис создаёт `cwd` и приватный каталог состояния адаптеров `cwd/.dsh-e2b`, проверяет, что зарезервированный путь — настоящий каталог, а не символическая ссылка или иной тип файла, затем назначает ему режим `0700`. Каждая внутренняя для адаптеров командная оболочка E2B получает свежий случайный корневой `HOME`, поэтому фиксированная login-оболочка SDK не разрешает profile-файлы из изменяемого домашнего каталога пользователя перед управляющей командой.

Освобождение ресурсов сначала запрещает новое получение дескриптора, затем дожидается завершения подготовки и удаляет песочницу. `SandboxNotFoundError` означает, что срок истёк либо другой владелец уже удалил её, и принимается как quiescence. Неудача начальной подготовки каталогов влечёт одну попытку удаления; настроенный таймаут E2B ограничивает вторую неудачу. Плагины-провайдеры **ДОЛЖНЫ** загружаться после этого владельца и освобождать ресурсы до него.

## Model Experience

Отсутствует: этот общий владелец рантайма не регистрирует видимого модели контекста; провайдерские адаптеры и их потребители владеют любыми отрисовываемыми эффектами.

#### KV Cache effect

Прямой инвалидации нет; этот пакет не добавляет токенов запроса.

## Известные ограничения и отложенная работа

- **Это не рантайм всего harness'а** — сервисы Cordis, состояние агента/сессии, журналы сессий, LLM-запросы, скиллы и буферы на стороне SDK остаются в хостовом процессе.
- **Состояние песочницы эфемерно** — освобождение ресурсов и таймаут удаляют песочницу; переподключение, удержание при паузе/выходе, шаблоны, тома и снапшоты находятся вне этого POC.
- **Платформа развёртывания не настраивается** — сетевая политика, синхронизация с хостовой рабочей областью и обнаружение песочниц находятся вне этого POC.
- **`cwd` — соглашение о разрешении путей, а не изоляция** — адаптеры и команды могут адресовать другие пути песочницы; сетевой доступ E2B сохраняет политику базового образа.
