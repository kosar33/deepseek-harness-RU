# examples/ — готовые к запуску демо-бандлы

[English](README.md) | [中文](README.zh.md) | Русский

Заранее собранные плагиновые бандлы, которые загружает тонкий листовой `cordis.yml`, избавляя от ручной сборки стержня и точки входа. Это **демонстрационные / справочные** пакеты: npm-суффикс `-demo` помечает каждый из них как непродуктовую поверхность, а назначение понятно прямо из имени пакета. Потребители — исполняемые листья в каталоге [`examples/`](../../examples/AGENTS.md) корня репозитория и [рантайм Python SDK](../../python/sdk-runtime/README.md); каждый потребитель — это лишь его сменные бэкенды плюс одна точка входа бандла.

| Пакет | npm-имя | Роль |
|---|---|---|
| [`agent-spine-demo/`](agent-spine-demo/README.ru.md) | `@deepseek-ai/dsh-agent-spine-demo` | Переиспользуемый бандл агентского стержня |
| [`acp-demo/`](acp-demo/README.ru.md) | `@deepseek-ai/dsh-acp-demo` | Бандл приложения ACP-автоматизации |
| [`jsonrpc-demo/`](jsonrpc-demo/README.ru.md) | `@deepseek-ai/dsh-sdk-jsonrpc-demo` | Рантайм JSON-RPC с внешней конфигурацией |

`agent-spine-demo` — общий бандл; `acp-demo` добавляет свою точку входа автоматизации, а `jsonrpc-demo` загружает дерево плагинов, принадлежащее самому развёртыванию. Разовое выполнение задач в продукте обслуживает `dsh --profile headless`; ни один пакет этого каталога такой возможности не даёт.

Эти пакеты не являются продуктовым API. Продуктовые capability seam и точки входа остаются в своих группах; демо-бандлы лишь выбирают конкретные композиции.

Не путайте эту группу с каталогом [`examples/`](../../examples/AGENTS.md) в корне репозитория: там лежат исполняемые **листья** `cordis.yml`, а эта группа содержит **бандлы**, которые те листья загружают.
