# @deepseek-ai/dsh-acp-demo

[English](README.md) | [中文](README.zh.md) | Русский

Приложение ACP-сервера автоматизации: стержень агента по умолчанию, создаваемые клиентом агенты через [`@deepseek-ai/dsh-acp`](../../acp/acp/README.md), персистентность JSONL и семантическое чекпоинтирование за одним JSON-RPC stdio-бином. Программные клиенты создают свежие сессии; этот пакет не монтирует никакого человеческого UI.

## Композиция

| Plugin | Role |
|---|---|
| `@deepseek-ai/dsh-agent-spine-demo` | Стержень агента без провайдеров и без заранее созданных агентов; каждый агент создаётся `session/new`. |
| `@deepseek-ai/dsh-session-persistence-jsonl` | Долговечные журналы сессий, используемые чекпоинтированием, наблюдаемостью и воспроизведением снапшотов. |
| `@deepseek-ai/dsh-session-checkpoint-policy` | Барьеры долговечности перед вызовами модели и верхнеуровневыми эффектами инструментов, плюс чекпоинты завершённых шагов. |
| `@deepseek-ai/dsh-session-query-sqlite` | Производный сервис точных/FTS-запросов к сессиям, открываемый до ACP-транспорта, чтобы листовые потребители были готовы к первому запросу модели. |
| `@deepseek-ai/dsh-acp` | Транспорт ACP только для автоматизации поверх stdin/stdout. |

Приложение не устанавливает команды, взаимодействие с пользователем, навигацию по сессиям, выборщики конфигураций или stdout-логгер. Оно владеет этими плагинами через один упорядоченный effect, поэтому сервис запросов готов прежде, чем ACP примет работу, а ACP-сессии уходят в quiescence прежде, чем чекпоинтирование и персистентность отсоединятся. Листовые конфигурации поставляют плагины LLM, исполнителя, песочницы, одобрения, файловой системы и обращённых к модели инструментов.

## Конфигурация

| Key | Default | Routed to |
|---|---|---|
| `provider` | требуется | Провайдерский маршрут для каждого созданного ACP агента. |
| `model` | требуется | Модель для каждого созданного ACP агента. |
| `maxParallelToolCalls` | умолчание agent-loop | Предел параллелизма вызовов инструментов — положительное целое число; `1` значит последовательно. |
| `persona` | — | Шаблон персона развёртывания для `dsh-system-prompt`. |
| `toolOrder` | лексикографический | Явный обращённый к модели порядок инструментов для `dsh-system-prompt`. |
| `tools` | `{ mode: 'native' }` | Нативный, Code Mode или комбинированный транспорт модельных инструментов. |
| `dshHome` | `$DSH_HOME` или `~/.dsh` | Домашний каталог Harness, разделяемый bash и обнаружением локальных скиллов. |
| `sessionTitle` | пределы примера-стержня | Долговечные пределы резервных заголовков; заголовки остаются вне ACP-провода. |
| `persistenceRoot` | `./.sessions` | Корень JSONL-бэкенда и родительский каталог производного индекса `session-query.db`. |
| `packChunks` | `true` | Упаковывать последовательные события delta-chunk в хранилище. |
| `persistenceCompression` | `zstd` | Фреймы Zstandard с контрольными суммами либо сырой `none`. |
| `workspaceContext` | требуется | Байтовый бюджет/конфигурация workspace-инструкций либо `false`. |
| `skills` | умолчания владельца | Реестр скиллов, локальный провайдер и обращённый к модели инструмент скиллов. |
| `toolBash` | умолчания владельца | Конфигурация обращённого к модели bash-инструмента. |
| `jobs` | `{ maxConcurrentJobsPerOwner: 10 }` | Локальное для процесса допущение активных задач на владельца. |
| `toolJobs` | умолчания владельца | Общая конфигурация управления фоновыми заданиями либо `false`. |
| `goals` | умолчания владельца | Персистируемый домен same-session целей и модельные инструменты целей либо `false`. |

Поставляемый [`examples/acp-agent/cordis.yml`](../../../examples/acp-agent/cordis.yml) добавляет адаптер DeepSeek, изолированные песочницей провайдеры bash и файловой системы, одноразовую политику одобрения, компакцию, субагентов, воркфлоу, хуки и обращённые к модели инструменты. Приложение поставляет производный индекс запросов сессий, тогда как обращённый к модели потребитель запросов остаётся явным opt-in листа. Оверлеи снапшотов заменяют только недетерминированные провайдеры или значения политик.

## Бин

`dsh-acp-demo [--config path-to-cordis.yml]` (короткая форма `-c`; по умолчанию `./cordis.yml`) загружает игнорируемый git-ом `.env`, кроме режима воспроизведения; `DSH_SNAPSHOT=replay` избирает соседний `cordis.snapshot.yml`; stdin EOF освобождает контекст и выталкивает сессии перед выходом. Установленная необязательная peer-зависимость Loader `node-addon-require-builtin` разрешает bare-спецификаторы плагинов для собранного бина под plain Node. Диагностика идёт в stderr, потому что stdout — это провод ACP.

## Model Experience

Косвенно — через `dsh-agent-spine-demo` и обращённые к модели плагины листа. Текст промпта ACP становится обычным журналируемым сообщением пользователя; метаданные протокола и выборы разрешений в запрос модели не входят.

#### KV Cache effect

Append-only на сессию; само приложение не добавляет содержимого в префикс запроса.

## Известные ограничения и отложенная работа

- **Персистентность JSONL фиксирована** — другой бэкенд потребует другой композиции.
- **Соседние плагины могут портить stdout** — приложение не может помешать другой записи писать байты вне протокола.
- **Только свежие сессии автоматизации** — возобновление и человеческое взаимодействие принадлежат другим входным точкам.
