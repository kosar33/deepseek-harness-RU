# @deepseek-ai/dsh-sdk-jsonrpc-demo

[English](README.md) | [中文](README.zh.md) | Русский

Приложение «только bin», которое загружает внешний `cordis.yml`; его запись [`jsonrpc`](../../sdk/server/README.ru.md) обслуживает SDK-клиентов по stdio, где кадры разделены переводами строк. Конфигурация собирает стержень, бэкенды и обслуживающий плагин. Публикуемый bin `dsh-jsonrpc-agent` разрешает bare-плагины относительно конфигурационного проекта. В [рантайме из одного исполняемого файла](../../../.agents/notes/implemented/architecture/2026-07-10-single-file-executable-sdk-runtime-distribution.md) Python SDK пакет `dsh-jsonrpc-agent-pkg` использует вместо неё `lib/packaged-bin.js`: упакованные bare-плагины разрешаются внутри его замкнутого дерева рантайма, тогда как относительные плагины остаются привязанными к конфигурации.

## Обнаружение конфигурации

Побеждает первый непустой канал: `$DSH_CORDIS_CONFIG`, затем позиционный `argv[2]`. Если ни один не указывает на существующий файл, бин печатает однострочную справку в stderr и завершается с кодом 1; ни рабочего каталога, ни встроенного запасного варианта нет. [`dsh-app-boot`](../../boot/app-boot/README.ru.md) делает отказ загрузки плагинов фатальным. Этот протокол не использует `DSH_SNAPSHOT`.

Конфигурация без `dsh-sdk-jsonrpc-server` корректна и ничего не обслуживает; серверный плагин бином не назначается.

## Жизненный цикл завершения

EOF stdin и `SIGTERM` освобождают корень до quiescence (полное завершение всех жизненных циклов) и завершают процесс с кодом 0; `SIGINT` после того же освобождения даёт код 130. EOF может оборвать выполняющийся ход, как описано в [Agent Note о дистрибуции](../../../.agents/notes/implemented/architecture/2026-07-10-single-file-executable-sdk-runtime-distribution.md). Плагин `jsonrpc` владеет протокольным завершением работы с гарантией «ответ до выхода»; оба пути идемпотентны и безопасны при гонке.

## stdout — это протокол

stdout несёт только кадры JSON-RPC. Бин и защитные проверки загрузки пишут диагностику в stderr, а конфигурация ДОЛЖНА опускать логгеры stdout.

## Model Experience

Опосредованно — через плагины, загружаемые из внешнего `cordis.yml`: им принадлежат все привязанные к модели промпты, схемы, сообщения и результаты; этот бин не добавляет ничего своего.

#### KV Cache effect

Прямой инвалидации нет; изменения префикса запроса находятся в ведении названного потребителя.

## Известные ограничения и отложенная работа

- **Бин не может доказать, что конфигурация обслуживает JSON-RPC** — корректная конфигурация без записи `dsh-sdk-jsonrpc-server` успешно загружается и ничего не обслуживает.
- **Встроенной или стандартной конфигурации нет** — каждый запуск обязан предоставить `DSH_CORDIS_CONFIG` или позиционный путь, а полное дерево плагинов и дисциплина stdout остаются за развёртыванием.
- **stdin EOF обрывает выполняющуюся работу** — исчезновение клиента немедленно освобождает корень; вызывающим, которым нужно упорядоченное завершение, следует использовать протокольный запрос `shutdown`.
