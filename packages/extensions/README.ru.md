# extensions/ — агент модифицирует собственный рантайм

[English](README.md) | [中文](README.zh.md) | Русский

Инструменты, обращённые к модели, поверх живого рантайма Cordis, внутри которого работает сам агент: инспектировать загруженные плагины и сервисный API, определять и выполнять динамические пакеты, написанные моделью, и снова их отзывать — плюс ограниченный рантайм плагинов из репозитория. Оба браузерных пакета живут здесь, а не под `packages/client/`, потому что они являются половинами двухполовинных пакетов этой подсистемы; хостовый агрегат исключает их, чтобы у каждой грани была собственная программа компилятора. Проектное обоснование: [Agent Note о self-referential наборе инструментов Cordis](../../.agents/notes/implemented/feature/2026-07-08-self-referential-cordis-toolset.md).

| Пакет | Роль | Ключ ctx |
|---|---|---|
| [`tool-cordis/`](tool-cordis/README.ru.md) | Инструменты для обращённой к модели инспекции рантайма и динамических пакетов | регистрируется на `ctx.tools` |
| [`cordis-host-runner/`](cordis-host-runner/README.ru.md) | Реестр определений, песочница `node:vm` для хостовых половин и полный цикл выполнения запроса | предоставляет `ctx.dynamicCordisRunner` |
| [`cordis-client-runner/`](cordis-client-runner/README.ru.md) | Браузерная половина двухполовинного пакета: превращает определение в работающий браузерный плагин и отвечает на запрос выполнения | клиентская грань; предоставляет браузерный `ctx.dynamicCordisRunner` |
| [`ui-cordis/`](ui-cordis/README.ru.md) | Браузерные поверхности: панель на весь фрейм, управляющая каждым определением, и карточка определения только для чтения | клиентская грань; регистрирует slot'ы |
