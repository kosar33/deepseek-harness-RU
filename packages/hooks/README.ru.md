# hooks/ — мосты хуков + общий протокол

[English](README.md) | [中文](README.zh.md) | Русский

Подсистема hooks позволяет пользователю расширять агента в точках жизненного цикла так же, как это делают Claude Code и Codex, — направляя плагин-мост на существующий `hooks.json` (или настройки), чтобы внешние shell-хууки выполнялись в точности. Каноническая поверхность расширения — типизированные точки перехвата самого harness ([Agent Note о точках перехвата](../../.agents/notes/implemented/feature/2026-06-30-interception-extension-points.md)); «нативный хук» — это просто обычный плагин Cordis на этих точках расширения. Эти пакеты — **мосты**, переводящие внешний протокол shell-хууков на ту же поверхность, плюс общая библиотека протокола передачи, на которой они построены.

| Пакет | Роль | Форма |
|---|---|---|
| [`hook-protocol/`](hook-protocol/README.ru.md) | Общая библиотека протокола shell-хууков | библиотека |
| [`hooks-claude-code/`](hooks-claude-code/README.ru.md) | Мост хуков Claude Code | плагин |
| [`hooks-codex/`](hooks-codex/README.ru.md) | Мост хуков Codex | плагин |

Общая библиотека владеет общим поведением протокола; каждый мост владеет привязкой событий своего диалекта. Эти контракты документируют дочерние README.
