# `@deepseek-ai/dsh-host-frontend-static`

[English](README.md) | [中文](README.zh.md) | Русский

SPA-сервер дистрибутива для веб-оболочки: функциональный плагин (конфиг `{distIndex}`), который занимает единственное запасное место [веб-сервера](../webserver/README.ru.md) и обслуживает собранный каталог фронтенда с явными точками входа индекса. Пока `distIndex` читаем, корень дистрибутива и настроенный путь индекса отдают `index.html` с HTTP 200; прочие существующие файлы отдаются напрямую. Отсутствующая или не являющаяся файлом цель внутри корня дистрибутива, включая отсутствующий настроенный индекс, возвращает пустой 404; выход за пределы корня дистрибутива даёт 403, неизвестные расширения отдаются как `application/octet-stream`, а не-GET/HEAD без совпавшего именованного маршрута — 405. Каждый успешный ответ индекса рендерится через `renderIndex` веб-сервера — сначала структурированные строки инъекций, затем сырые taps индекса, — именно так загрузочный манифест попадает на страницу. `distIndex` — сборочный факт компонующего приложения: [`dsh-web-app`](../../bundle/web-app/README.ru.md) разрешает его через экспорты пакета фронтенда и монтирует этот плагин; развёртывание никогда не прописывает его вручную.

Запасное место принадлежит одному владельцу (повторное занятие бросает исключение) и ограничено временем жизни эффекта: освобождение ресурсов fiber плагина высвобождает место, после чего веб-сервер без занятого места отвечает 404.

## Model Experience

Отсутствует: пакет обслуживает браузерные ассеты; ничто из него не попадает в запрос к модели.

#### Влияние на KV-кэш

Отсутствует; пакет ни собирает, ни отправляет запрос к провайдеру.

## Известные ограничения и отложенная работа

- **Стартовая MIME-таблица минимальна** — она покрывает набор ассетов, выдаваемых Vite, плюс поставляемый PWA-манифест; прочие расширения откатываются к `application/octet-stream`, пока какой-либо класс ассетов действительно не появится.
- **Маршрутизация по путям явная** — текущий клиент входит через корень или настроенный путь индекса и не имеет pathname-маршрутов History API. Добавление такого маршрута требует явного правила на сервере и покрытия реальной композицией, а не широкого резервного ответа на любой промах.
