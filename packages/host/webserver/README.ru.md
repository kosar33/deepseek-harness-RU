# @deepseek-ai/dsh-host-webserver

[English](README.md) | [中文](README.zh.md) | Русский

Плагин регистрации HTTP- и upgrade-маршрутов веба (экспортируемый по умолчанию `WebServer`, конфиг `{host, port}`): сервер `node:http`, который начинает слушать при активации и предоставляет `ctx.webServer`. `register(route)` добавляет именованный HTTP-маршрут `exact`/`prefix`; `registerUpgrade(route)` добавляет upgrade-маршрут для точного pathname. Дубликат пути в любой из таблиц бросает исключение: шаблоны маршрутов — контракт уровня композиции, а коллизия — ошибка конфигурации; оба метода возвращают disposer, снимающий регистрацию. `registerFallback(handler)` регистрирует единственный обработчик запросов, не совпавших ни с одним именованным маршрутом. Вторая регистрация бросает исключение; владелец в поставке — сервер SPA dist [`dsh-host-frontend-static`](../frontend-static/README.md), а пока никто не зарегистрирован, сервер отвечает 404. Стартовые входы индекса — структурированные строки: `collectIndexInjections()` собирает свежую таблицу `IndexInjection` за одно событие `webserver/index-inject` на вызов, а `renderIndex(html)` рендерит строки в тело index.html перед применением сырых преобразований `tapIndex(transform)` в порядке регистрации (`applyIndexTaps(html)` — запасной выход для разметки, которую не выражает ни одна строка); обработчик отката вызывает `renderIndex` на каждом ответе индекса, а статическое развёртывание поставляет те же строки в своей загрузочной полезной нагрузке и рендерит их экспортируемой `renderIndexInjections`. `port` читает порт прослушивания (значение, назначенное ОС, когда `port` равен 0), а `host` читает настроенный хост привязки (факты времени композиции, под которые подстраиваются другие плагины, например выбор directory-picker). Порядок сопоставления HTTP фиксирован: exact по всей таблице, затем самый длинный prefix, затем обработчик отката. Upgrade-маршруты сопоставляются точно, несовпавшие соединения закрываются; порядок регистрации не несёт никакой семантики для запросов.

Пакет не знает понятий harness и не раздаёт файлов: HTTP-мост `/api` и нисходящие WebSocket'ы — маршруты, которыми владеет плагин соединения; бандлы плагинов и поток событий HMR — маршруты, которыми владеют плагины modules/hmr; раздача dist принадлежит владельцу отката. Обработчик upgrade владеет рукопожатием протокола и содержимым соединения; webserver лишь доставляет сырой сокет и запрос. `host` принимает только `127.0.0.1` (положение по умолчанию) и `0.0.0.0` (намеренная экспозиция в сеть). Этот сервер обслуживает только браузеры; Electron грузит dist через `file://` и переносит fetch через IPC-мост. Этот пакет никогда ничего не печатает; строка URL принадлежит оболочке.

Сбой прослушивания (EADDRINUSE…) выбрасывает исключение из активации и отклоняет композицию Loader'а с диагностикой привязки; неудавшийся fiber-кандидат освобождается. HTTP-запрос, обработка которого бросила исключение (`decodeURIComponent` у владельца отката на искажённой %-последовательности, обрыв соединения клиентом посреди тела), получает ответ 400 — либо уничтожение сокета, когда заголовки уже отправлены, — и журналируется предупреждением; процесс он никогда не завершает. Исключение в обработчике upgrade или транспортная ошибка upgraded-сокета журналируется предупреждением и уничтожает его сокет. Освобождение ресурсов запускает `close()` и `closeAllConnections()`, уничтожает каждый отслеживаемый upgraded-сокет и возвращается только после того, как HTTP-сервер и эти сокеты закрылись.

## Опыт модели

Отсутствует: пакет — веб-носитель между браузером и HTTP/upgrade-маршрутами, которые регистрируют другие плагины; ничто отсюда не достигает запроса к модели.

#### Влияние на KV-кэш

Отсутствует; этот пакет ни собирает, ни отправляет запрос провайдеру.

## Известные ограничения и отложенная работа

- **Нет TLS, аутентификации и политики источника** — привязка к адресу вне loopback выставляет сервер этой сети; укрепление развёртывания (или прикрытие настоящим обратным прокси) намеренно остаётся вне области видимости ориентированной на разработчиков версии v1.
- **Опции сокета зафиксированы** — конфигурация выбирает хост и порт привязки, тогда как backlog и прочие настройки сокета остаются внутренними, пока какое-нибудь развёртывание их не затребует.
