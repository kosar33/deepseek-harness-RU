# @deepseek-ai/dsh-anonymous-user-id

[English](README.md) | [中文](README.zh.md) | Русский

Разделяемая анонимная идентичность для телеметрии сессий, подтверждения прямых отзывов и запросов к провайдеру DeepSeek. `getOrCreateAnonymousUserId()` возвращает случайный UUID v4 в области одного home-каталога харнесса, сохраняемый единственной строкой в файле `$DSH_HOME/.anonymous-user-id` (`~/.dsh/.anonymous-user-id`, когда `DSH_HOME` не задан). Бэкенд OpenTelemetry сообщает его как Resource `user.id`; `/feedback` включает то же значение в своё подтверждение; а `dsh-llm-deepseek` отправляет его как `x-deepseek-harness-user-id`, позволяя принимающим системам сопоставлять записи без независимо сгенерированных идентичностей.

Идентичность никогда не выводится из имени хоста, сетевого адреса, git remote или иного идентифицирующего источника. Удаление `.anonymous-user-id` сбрасывает идентичность при следующем запуске процесса. Разные home-каталоги харнесса имеют разные идентичности.

## Контракт хранения

Чтение и запись синхронны, поскольку и построение телеметрии во время загрузки, и выполнение прямых команд нуждаются в одном API. Результат мемоизируется на время жизни процесса по разрешённому пути файла. Первый писатель использует эксклюзивное создание, а проигравший параллельную гонку процесс принимает сохранившегося победителя; повреждённый файл заменяется. Персистентность — best-effort, поэтому home-каталог, недоступный для записи, всё равно получает локальный для процесса UUID вместо блокировки телеметрии или обратной связи.

## Композиция

Этот пакет — разделяемая библиотека, а не плагин Cordis. Потребители импортируют `getOrCreateAnonymousUserId()` напрямую. Его компаньон-инвариант намеренно пуст, потому что пакет не владеет ни потоком событий, ни публичным изменяемым отношением, которые можно было бы проверить, не создавая идентичность как побочный эффект. `DSH_TELEMETRY_DISABLED` останавливает только экспорт телеметрии; он не подавляет ни подтверждение прямых отзывов, ни заголовок провайдера DeepSeek.

## Model Experience

Никакого, поскольку идентификатор достигает DeepSeek только как скрытые от модели транспортные метаданные HTTP и никогда не попадает в тело запроса, промпт или видимое модели содержимое.

#### KV Cache effect

Никакого; транспортный заголовок не меняет ни токены, ни видимый модели префикс.

## Known Limitations and Deferred Work

- **Восстановление после удаления отсутствует** — утрата намеренно создаёт новую анонимную идентичность; восстановление требовало бы стабильного материала для выведения идентичности, что ослабило бы анонимность.
- **Конкурентность — best-effort** — читатель, попавший в узкий интервал между эксклюзивным созданием файла параллельным процессом и завершённой записью, может использовать другой находящийся в памяти UUID для этого запуска; последующие запуски сходятся к сохранённому значению.
- **Идентичности между home-каталогами нет** — разные значения `$DSH_HOME` невозможно сопоставить между собой.
- **Настроенные шлюзы DeepSeek получают идентификатор** — `dsh-llm-deepseek` отправляет стабильный заголовок своему разрешённому `baseURL`, включая переопределения развёртывания, независимо от режима разделения телеметрии.
