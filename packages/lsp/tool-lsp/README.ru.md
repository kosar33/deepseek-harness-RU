# @deepseek-ai/dsh-tool-lsp

[English](README.md) | [中文](README.zh.md) | Русский

Обращённый к модели **инструмент `lsp`** поверх `ctx.lsp`: один read-only инструмент с четырьмя операциями для точной навигации по коду. Он владеет модельной схемой, наставлениями в промпте, преобразованием координат, лимитами и форматированием результатов и презентацией в UI; провайдера он не импортирует.

Плагин-пространство имён (`name` / `inject` / `Config` / `apply`, без default export). Внедряет `tools`, `lsp` и `systemPrompt`.

## Инструмент

`lsp` принимает `operation` (`goToDefinition` | `findReferences` | `goToImplementation` | `hover`), `file_path`, `line` и `character`. `line` и `character` — положительные координаты курсора UTF-16 с отсчётом от единицы; инструмент преобразует их в позиции seam с отсчётом от нуля и преобразует отрендеренные локации обратно. `findReferences` включает объявления, чтобы анализ влияния не упускал определяющее место. Провайдер, id языка, корень рабочей области, лимиты, таймаут, инициализация и исполняемый файл остаются вне модельного ввода.

Инструмент требует корень рабочей области из `header.cwd` сессии и не имеет запасного варианта: при отсутствии инструмент завершается ошибкой `LSP_WORKSPACE_REQUIRED` ещё до запроса. Его канонический результат — полное нормализованное объединение Service Definition: `{ kind: "locations", locations, resolvedWorkspaceUri }` или `{ kind: "hover", hover }`; Code Mode может напрямую инспектировать каждую полученную локацию и диапазон с отсчётом от нуля. Нативный рендеринг проецирует стабильные записи `path:line:character`, сгруппированные по файлам, против канонического URI рабочей области провайдера, а не применяет правила путей хост-платформы к cwd сессии. URI `file:` становится путём относительно рабочей области внутри этого URI либо выведенным из URI абсолютным путём вне его; искажённые и не-`file:` URI остаются дословно. Пустые локации и `null` hover — удачные ответы без результата; искажённые payload'ы провайдера остаются структурными ошибками.

## Конфигурация

| Ключ | По умолчанию | Значение |
|---|---|---|
| `maxLocations` | `100` | Наибольшее число отрендеренных локаций до маркера пропуска. |
| `maxResultChars` | `16000` | Наибольший полный отрендеренный результат, включая метаданные усечения. |
| `timeoutMs` | `60000` | Бюджет таймаута вызова инструмента, применяемый `dsh-tool-call-timeout-policy`; покрывает полный жизненный цикл «очередь — открытие/запрос/закрытие» и не конфигурируется моделью. |

## Model Experience

### Системный промпт

#### Что видит модель

Один раздел системного промпта (порядок 112) позиционирует LSP как вспомогательное средство точности со следующим текстом:

##### Дословные наставления

```markdown
Use search/read for ordinary navigation. Use lsp when textual matches are ambiguous or before a change requires precise definitions, implementations, or references. Positions are one-based line and character (UTF-16) at the cursor; an off-symbol position may return no results. findReferences always includes the declaration.
```

#### Эффект на токены

Фиксированная стоимость наставлений в каждом запросе, пока плагин активен.

#### KV Cache effect

Префикс стабилен, пока область плагина и текст наставлений неизменны; активация или освобождение ресурсов могут инвалидировать переиспользование этого раздела.

### Схема инструмента

#### Что видит модель

Модель видит сгенерированную [схему `lsp`](../../../docs/tool-catalog.ru.md#deepseek-aidsh-tool-lsp).

#### Эффект на токены

Фиксированная стоимость схемы в каждом запросе, пока она включена; бюджет `timeoutMs` никогда не отправляется модели.

#### KV Cache effect

Префикс стабилен, пока видимое определение инструмента и его порядок неизменны; жизненный цикл регистрации или ограничение областей могут инвалидировать переиспользование с первого изменившегося токена схемы.

### Результаты

#### Что видит модель

Строки локаций `path:line:character`, сгруппированные по файлам, или нормализованный текст hover, ограниченные сперва `maxLocations`, а затем `maxResultChars`; маркеры пропуска и усечения входят в полный символьный предел. Эти пределы затрагивают только нативную/модельную презентацию, но не каноническое значение. Пустые результаты используют различимые строки `No results.` / `No hover information.`.

#### Эффект на токены

Ограничены на каждый результат инструмента `maxResultChars`, при этом `maxLocations` дополнительно ограничивает число элементов навигации.

#### KV Cache effect

Результаты инструмента добавляются после кэшированного префикса запроса и не инвалидируют его напрямую.

### Презентация в UI

#### Что видит модель

Ничего. Клиент рендерит общую карточку поиска — `{ card: 'generic', kind: 'search', title, locations: [{ path, line }] }` — чей заголовок, выведенный из аргументов, несёт операцию и курсор с отсчётом от единицы; режим сопровождения фокусирует запрошенную строку, а заголовок сохраняет столбец.

#### Эффект на токены

Нулевой прямой эффект на токены, поскольку рендеринг происходит только на клиенте.

#### KV Cache effect

Отсутствует: презентация в UI находится вне модельного запроса.

## Known Limitations and Deferred Work

- **Курсорные координаты UTF-16** — столбцы точны для протокола, но трудны для модельного подсчёта вокруг не-BMP символов; позиция вне символа может вернуть пустые результаты, поэтому промпт объясняет соглашение, не поощряя широкое применение LSP ([Agent Note о seam](../../../.agents/notes/implemented/architecture/2026-07-15-lsp-capability-seam.md)).
- **Нет обещания полноты между серверами** — поддерживаемые серверы могут возвращать пустые или частичные результаты в зависимости от готовности индексации; инструмент не обещает полноты между языками или серверами.
