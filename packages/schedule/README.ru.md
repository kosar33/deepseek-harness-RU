# schedule/ — напоминания, локальные для сессии

[English](README.md) | [中文](README.zh.md) | Русский

Семейство Schedule владеет напоминаниями, чьё долговечное состояние живёт в исходном журнале Session. Локальный относительно процесса владелец ждёт лишь до тех пор, пока у этой Session есть живой корневой Agent; холодные Session возобновляют просроченную работу, когда снова становятся живыми, и никогда не подразумевают внешний канал уведомлений.

| Пакет | Роль | ctx-ключ |
|---|---|---|
| `schedule/` | Версионированные события и свёртка Schedule, обращённые к модели инструменты create/list/delete и владелец таймеров живого корневого Agent | — |

Пакет намеренно не открывает ни публичного сервиса Schedule, ни изменяемой базы данных. Инструменты и рантайм дописывают в поток Session; подошедшая по сроку работа входит в ту же беседу через обычную очередь последующих ходов Agent.

Контракты долговечной записи, переходов, представления и доставки см. в [Schedule, локальном для сессии](../../docs/subsystems/schedule.ru.md).
