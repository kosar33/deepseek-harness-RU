# skill/ — семейство возможностей скиллов

[English](README.md) | [中文](README.zh.md) | Русский

Это семейство находит переиспользуемые агентские инструкции и открывает их модели через независимый от провайдера каталог и загрузчик.

| Package | Role | ctx key |
|---|---|---|
| [`skill/`](skill/README.ru.md) | Определяет регистрацию и поиск провайдеров скиллов | `ctx.skills` |
| [`skill-badge/`](skill-badge/README.ru.md) | Добавляет опциональный комплектный скилл dsh badge | регистрируется на `ctx.skills` |
| [`skill-filesystem/`](skill-filesystem/README.ru.md) | Находит скиллы на локальных файловых системах | регистрируется на `ctx.skills` |
| [`tool-skill/`](tool-skill/README.ru.md) | Публикует каталог скиллов и обращённый к модели загрузчик | регистрируется на `ctx.tools` |

Эта возможность остаётся вне управляющего стержня ядра и может использовать локальных, встроенных или удалённых провайдеров, не меняя обращённый к модели контракт.

Справочник подсистемы — приоритет обнаружения, снапшоты каталога, загрузчик `skill` — находится в [docs/subsystems/skills.ru.md](../../docs/subsystems/skills.ru.md).
