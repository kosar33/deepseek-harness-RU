# @deepseek-ai/dsh-skill-badge

[English](README.md) | [中文](README.zh.md) | Русский

Опциональный комплектный провайдер скиллов, добавляющий `dsh-badge` в `ctx.skills`. Скилл поставляет официальные Markdown-сниппеты «powered by dsh» и упакованный PNG для систем, которые не могут надёжно импортировать удалённое изображение.

Монтирование плагина включает провайдера. Конфигурации у него нет. В штатной CLI-композиции плагин присутствует со значением `disabled: true`; пользователи должны явно включить его строку `skill-badge`, прежде чем скилл попадёт в каталог.

Провайдер публикует свой упакованный каталог `assets/` как базу ресурсов скилла. `dsh-badge.png` — исходный ассет размером 726×120, а потребители отрисовывают его в 121×20.

## Влияние на модель

Косвенно — через `@deepseek-ai/dsh-tool-skill`, который отрисовывает запись каталога и тело выбранного скилла.

#### Влияние на KV-кэш

Выключенный по умолчанию плагин не меняет ни одного запроса. Во включённом состоянии его запись каталога и любое загруженное тело меняют KV-префикс провайдера в точках их вставки.

## Известные ограничения и отложенная работа

- Провайдер добавляет один фиксированный скилл и не допускает настройки в рантайме.
- Удалённый Markdown использует Shields.io; используйте упакованный PNG, когда целевая система не может надёжно получать удалённые изображения.
