# @deepseek-ai/dsh-storage

[English](README.md) | [中文](README.zh.md) | Русский

Хаб хранения (`ctx.storage`) для внесессионных данных: реестр именованных бэкендов плюс смонтированные формы данных. Сам хаб не выполняет никакого IO — носителями владеют бэкенды, а семантикой формы данных. [Обзор семейства хранения](../README.ru.md) сопоставляет эти пакеты; [Agent Note о доменном KV-хранилище](../../../.agents/notes/proposed/architecture/2026-07-24-domain-kv-storage-and-workspace.md) фиксирует обоснование дизайна.

## Устройство

- `ctx.storage.backend` — таблица «имя → бэкенд». Несколько бэкендов остаются смонтированными рядом (`json`, `sqlite`); какой бэкенд обслуживает потребителя, решает конфигурация этого самого потребителя (таблица маршрутов доменного слоя), но никак не глобальный выбор хаба. `register()` возвращает функцию освобождения ресурсов; дубликаты имён и обращения по неизвестным именам завершаются громким отказом (fail loud).
- `ctx.storage.mount(form, facility)` / `ctx.storage.form(form)` — монтирование форм данных. `StorageForms` расширяем слиянием (merge-extensible); доменный слой вливает `domain`, и к нему обращаются как `ctx.storage.domain`.
- Бэкенд владеет одним носителем и открывает поддерживаемые им фасеты формы данных. Текущая фасета — `kv`; её точный контракт живёт в `src/backend.ts`.

## Влияние на модель

### Регистрации бэкендов и форм

#### Что видит модель

Ничего. `ctx.storage` — хостовая таблица регистраций; хаб не регистрирует инструментов, не вводит промптов и не пишет событий сессии.

#### Влияние на токены

Ноль прямых токенов на каждом запросе.

#### Влияние на KV-кэш

Не зависит от живых запросов: хаб никогда не касается префикса запроса, поэтому не может инвалидировать переиспользование провайдерского кэша.

## Известные ограничения и отложенная работа

- **`kv` — единственная форма данных** — бэкендам пока есть лишь одна фасета для реализации.
- **Формы разрешаются лениво** — чтение `ctx.storage.domain` до монтирования доменного плагина бросает `form-not-mounted`; сборки упорядочивают плагины соответственно (ошибка конфигурации падает громко, а не молчаливо откладывается).
