# `@deepseek-ai/dsh-agent-loop-testkit`

[English](README.md) | [中文](README.zh.md) | Русский

Общее монтирование предварительных зависимостей для тестов, упражняющих конкретный `AgentLoop`. `mountAgentLoopTestDependencies(ctx, options?)` устанавливает сервисы LLM, сессии, системного промпта, инструментов и агентов в порядке зависимостей, затем возвращается до монтирования цикла.

Вызывающий регистрирует адаптеры и необязательные плагины, монтирует `AgentLoop` с проверяемой конфигурацией и освобождает ресурсы собственного Context. Конфигурация системного промпта и реестра инструментов может быть передана через `options`; помощник не предоставляет тестовых умолчаний сверх тех, которыми владеют сервисы. Отказ загрузки плагина отклоняет вызов помощника, а сервисы, активированные раньше по последовательности, остаются во владении Context вызывающего.

```ts
import { Context } from '@deepseek-ai/cordis'
import AgentLoop from '@deepseek-ai/dsh-agent-loop'
import { mountAgentLoopTestDependencies } from '@deepseek-ai/dsh-agent-loop-testkit'

const ctx = new Context()

await mountAgentLoopTestDependencies(ctx)
// Register the test adapter and any optional plugins here.
await ctx.plugin(AgentLoop, { agents: [] })
```

Тесты отказов инъекции, частичной топологии, порядка загрузки сервисов или освобождения ресурсов сервисов монтируют зависимости напрямую, вместо того чтобы пользоваться этим помощником.

## Влияние на модель

Отсутствует: этот помощник композиции, предназначенный только для тестов, не приводит в действие и не изменяет запросы к модели.

#### Влияние на KV-кэш

Отсутствует; этот пакет не собирает и не отправляет запросы к провайдеру.

## Известные ограничения и отложенная работа

- **Общим является только обязательный стержень предварительных зависимостей** — адаптеры, необязательные плагины, `AgentLoop`, агенты и освобождение ресурсов Context остаются во владении вызывающего, чтобы специфичный для сценария порядок оставался видимым.
