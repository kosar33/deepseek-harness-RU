# @deepseek-ai/dsh-llm-replay

[English](README.md) | [中文](README.zh.md) | Русский

LLM-плагин воспроизведения для безключевых снапшот-тестов. Он выдаёт модельные потоки, восстановленные из записанной фикстуры **session JSONL**, поэтому тест может поднять настоящего агента против фиксированного модельного транскрипта без API-ключа. С настроенными `providers` он регистрирует адаптер чистого воспроизведения, каталог которого доступен сценариям, упражняющим обнаружение моделей; без `providers` он устанавливает всеохватный каскад `llm/stream`, которым пользуются тесты, не нуждающиеся в обнаружении.

Его потребители — снапшот-сьюты ACP и headless `stream-json`, а также e2e-линия веб-браузера. Сьюты, собираемые через Loader, монтируют этот плагин вместо настоящего LLM-адаптера; веб-линия устанавливает его напрямую, чтобы сохранить дескриптор потребления teardown.

## Как устроена фикстура

Фикстура — проекция персистентного журнала сессии (`<scenario>/session.jsonl`): она хранит заголовок и payload каждого события, но опускает конверты `seq`/`time` тела (`seq0`/`time0` для упакованных строк). Воспроизведение при разборе восстанавливает сплошные синтетические конверты; один файл ДОЛЖЕН содержать либо проецированные строки тела, либо полные персистентные строки тела, но никогда оба. Рантайм-персистентность по-прежнему пишет полный журнал. События `assistant/chunk` фикстуры несут каждый `StreamChunk`, поэтому их группировка по `(turn, step)` восстанавливает последовательность чанков каждого вызова `stream()` agent-loop. Удачный суммаризатор компакции журналируется иначе: когда `compaction/summary` несёт `llmStreamCall: true` и свой полный `rawOutput`, воспроизведение реконструирует канонический удачный поток в позиции того события, используя одну пару `block-start`/`block-end` на блок, записанный расход токенов, когда он есть, и терминальный `stop`. Точное разделение провайдерских дельт — не часть долговечного результата компакции. `rawOutput` без маркера не подразумевает локального вызова LLM, потому что шаблонный и удалённый суммаризаторы могут удерживать полный вывод, не пользуясь адаптером этого контекста.

Запись, следовательно, — это «прогони настоящего агента однажды и собери `.jsonl`», что делает снапшот-harness; этот плагин ничего не записывает. Фикстура может нести содержимое своего `request/header`, затокенизированное в `{{system}}`/`{{tools}}` (harness закрепляет это содержимое в одном сценарии и вычищает остальные); воспроизведению это безразлично — вывод скрипта читает только события `assistant/chunk` и `compaction/summary` плюс заголовок сессии в строке 0.

Два режима отказа не восстановимы из одного `assistant/chunk` — чистый бросок до всякого чанка (например, HTTP 401, где журнал хранит только `turn/end {error}` и ни одного чанка) и отмена/зависание (тайминг, а не содержимое чанков). Сценарий, которому они нужны, поставляет сопутствующий файл (`<scenario>/replay.override.json`), который либо заменяет выведенный скрипт (голый `ReplayEntry[]`), либо дополняет его (`{ patches: [{ at, entry }] }`: сохранить каждый вызов, выведенный из JSONL, и подменить названные индексы вызовов с нулевой базой; `at`, равный длине выведенного, добавляет повторную попытку после инъецированного преходящего броска). Индексы патчей ДОЛЖНЫ быть уникальными. Документ override, каждый патч и запись и каждый дискриминант чанка валидируются при загрузке файла. Запись `hang` может назвать `readyFile`; воспроизведение пишет тот пустой маркер после того, как его префиксные чанки доходят до цикла, и до ожидания отмены, поэтому внешний драйвер может отменять детерминированно, не наблюдая обновления представления.

Скриптованная строка может встроить `{{fromRequest:<regex>}}`, чтобы заполнить значение, которого статический sidecar знать не может, — например, случайно отчеканенный goal id, который модель ДОЛЖНА вернуть эхом в `update_goal`. В момент потока каждый плейсхолдер разрешается против живого запроса: корпус — это все строковые листья сообщений запроса, соединённые переводами строк, побеждает ПОСЛЕДНЕЕ совпадение шаблона в корпусе, а его первая группа захвата (или всё совпадение, если группы нет) подставляется на место. Шаблон, не совпавший ни с чем, недопустимый шаблон и незакрытый плейсхолдер каждый отказывают громко. Последние две фигурные скобки подряд идущей серии `}` завершают плейсхолдер, поэтому шаблон может заканчиваться квантификатором в фигурных скобках (`[0-9a-f]{4}`), но не может содержать `}}` с последующим содержимым шаблона. Разрешение применяется к каждой скриптованной записи, включая выведенные из записанного JSONL, — записанная фикстура, чей текст законно содержит литеральный маркер, ДОЛЖНА быть выражена через sidecar без него.

## Вложенные агенты: ключи на сессию

Сценарий, где родительский агент делегирует внутрипроцессным субагентам, записывает более одного журнала: родительский (`session.jsonl`) плюс по одному на ребёнка (`session.1.jsonl`, …). Каждый агент работает как собственная `Session` на том же контексте, поэтому воспроизведение ДОЛЖНО обслуживать каждого собственным скриптом.

Воспроизведение ключует каждый вызов по id вызывающей сессии (`GenerateOptions.sessionId`, проставляемый agent loop). Живые id сессий при каждом запуске заново случайны и никогда не равны записанным, поэтому живая сессия связывается с записанным скриптом по **порядку первого вызова**: скрипты упорядочены по `createdAt` заголовка (родитель первым — он начинает поток раньше, чем сможет делегировать), первая живая сессия, сделавшая хоть какой-то вызов, забирает первый скрипт, следующая новая сессия — следующий и так далее. Затем каждая сессия продвигает собственный курсор. Вызов без `sessionId` — одна анонимная сессия, связанная с первичным скриптом. Число различных живых сессий сверх числа записанных скриптов — громкий отказ.

## Конфигурация

| Ключ | Тип | По умолчанию | Примечания |
|---|---|---|---|
| `file` | string | `$DSH_SNAPSHOT_FILE` | Путь к первичной (родительской) фикстуре `session.jsonl`. Обязателен (конфиг или env). |
| `overrideFile` | string | `$DSH_SNAPSHOT_OVERRIDE` | Опциональный сопутствующий файл `ReplayOverrideDoc` для первичной сессии: голый `ReplayEntry[]` заменяет её выведенный скрипт, а `{ patches }` дополняет его по индексу вызова. |
| `childFiles` | string[] | `$DSH_SNAPSHOT_CHILD_FILES` (разделены путём) | Записанные журналы дочерних сессий субагентов для вложенного сценария; пусто для односессионного сценария. |
| `providers` | `ReplayProviderConfig[]` | — | Опциональные каталог провайдеров и моделей только для воспроизведения. Каждый провайдер может задать `retryPolicy`, каждая модель может опубликовать `contextWindow` и массив `inputModalities`, содержащий только `text` и `image`; недопустимые модальности валят загрузку плагина. Настроенные маршруты диспетчеризуются через адаптер воспроизведения и никогда не выполняют провайдерского ввода-вывода. |
| `paceMs` | number | — (burst) | Опциональная задержка на чанк в мс, чтобы нижестоящие транспорты (например, веб-SSE mux, наблюдаемый настоящим браузером) видели по-настоящему инкрементальную доставку. Только ручка реализма — тесты НЕ ДОЛЖНЫ зависеть от неё для корректности. Неотрицательное целое; отмена во время ожидания pace быстро отменяет поток. |

```yaml
- id: llm-replay
  name: '@deepseek-ai/dsh-llm-replay'
  config:
    providers:
      - id: deepseek-official
        name: DeepSeek
        retryPolicy:
          mode: normal
          backoff:
            initialDelayMs: 1
            maxDelayMs: 1
            jitterRatio: 0
        models:
          - id: deepseek-v4-flash
            contextWindow: 128000
          - id: deepseek-v4-pro
  # file/overrideFile/childFiles default to $DSH_SNAPSHOT_FILE /
  # $DSH_SNAPSHOT_OVERRIDE / $DSH_SNAPSHOT_CHILD_FILES, set by the snapshot
  # harness per scenario.
```

## Экспорты

- `installLlmReplay(ctx, config)` — устанавливает настроенный адаптер воспроизведения или всеохватный слушатель `llm/stream`; возвращает `ReplayHandle` (`dispose()` для HMR-безопасности плюс `assertConsumed()`, проверка teardown, что каждый записанный скрипт связался с живой сессией и каждый связанный курсор осушён, — превращает сценарий, молча прогнавший меньше модельных вызовов, чем записано, в отчётливую диагностику). Используйте в тестах, чтобы гонять воспроизведение без Loader и env-переменных.
- `loadSessionScripts(config)` — разрешает упорядоченный `SessionScript[]` (первичный + дети) для сценария, готовый связываться с живыми сессиями в порядке первого вызова.
- `loadReplayScript(config)` — разрешает `ReplayEntry[]` только для первичной сессии (валидированная замена/патчи из sidecar, если есть, иначе вывод из JSONL; громкий отказ, если фикстуры нет).
- `deriveReplayScript(events)` / `parseSessionLog(text)` / `parseSessionHeader(text)` / `resolveScriptedEntry(entry, messages)` — чистые помощники, которые превращают обычные чанки цикла и явно помеченные локальные выводы компакции в персистентном или спроецированном журнале сессии в скрипт, читают `id`/`createdAt` его заголовка и разрешают плейсхолдеры `{{fromRequest:...}}` против одного живого запроса. Выведенная ассистентская группа ДОЛЖНА заканчиваться чанком `finish`; группа без него — отпечаток брошенного `stream()`, и выражена такая ситуация ДОЛЖНА быть через sidecar override.
- Типы `ReplayEntry` / `ReplayOverrideDoc` / `ReplayOverridePatch` / `SessionScript` / `ReplayConfig` / `ReplayProviderConfig` / `ReplayModelConfig` / `ReplayHandle` / `Config`.

## Форма экспорта плагина

Именованные `name` / `inject` / `Config` / `apply`, **без экспорта по умолчанию**: `unwrapExports` cordis Loader делает `exports.default ?? exports`, поэтому случайный default свернул бы модуль в голую функцию и потерял пространство имён `inject` (см. [docs/postmortem/0001](../../../docs/postmortem/0001-acp-default-export-drops-inject.ru.md)).

## Model Experience

Отсутствует: этот безключевой тестовый адаптер не отправляет запроса модели провайдера; он лишь проигрывает записанные ассистентские чанки в тестовый цикл.

#### KV Cache effect

Отсутствует; этот пакет ни собирает, ни отправляет запроса к провайдеру.

## Known Limitations and Deferred Work

- **Связывание скриптов по порядку первого вызова предполагает последовательную делегацию** — раскрой, запускающий братские субагенты конкурентно, связывал бы живые сессии с записанными скриптами недетерминированно; более сильное ключевание отложено, пока такой сценарий не появится (`XXX(concurrent-subagents)`).
- **Выводимы только обычные чанки цикла и помеченные локальные выводы компакции** — чистый бросок до чанка, отмена/зависание или непомеченный вызов внешнего суммаризатора требуют sidecar `replay.override.json`. Формы замены и патчей действуют только на первичную сессию; детские скрипты по-прежнему выводятся из своих журналов.
