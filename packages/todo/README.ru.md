# todo/ — семейство возможности todo / планирования

[English](README.md) | [中文](README.zh.md) | Русский

Обращённая к модели возможность todo. Это один **продуктовый** пакет, потому что списком владеет одна агентская сессия; сменяемого провайдерского контракта нет.

| Package | Role | ctx key |
|---|---|---|
| [`tool-todo/`](tool-todo/README.ru.md) | Хранит и открывает список todo сессии. | (регистрируется на `ctx.tools`) |

Контрактом инструмента, персистентности и рендеринга владеет README дочернего пакета.

Полезная нагрузка события задокументирована в [docs/subsystems/session.ru.md](../../docs/subsystems/session.ru.md).
