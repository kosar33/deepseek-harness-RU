# util/ — низкоуровневые общие утилиты

[English](README.md) | [中文](README.zh.md) | Русский

Эти пакеты без внешних зависимостей предоставляют небольшие примитивы, общие для нескольких семейств возможностей. Бизнес-семантика остаётся за каждой использующей их возможностью.

| Пакет | Роль |
|---|---|
| [`brand/`](brand/README.ru.md) | Поставляет номинально брендированные типы |
| [`paths/`](home-paths/README.ru.md) | Разрешает корень данных Harness и общие пути |
| [`timeout/`](timeout/README.ru.md) | Поставляет примитивы дедлайнов и классификации таймаутов |
| [`retention/`](output-retention/README.ru.md) | Ограничивает удерживаемые коллекции текста и элементов |
| [`atomic-write/`](atomic-write/README.ru.md) | Атомарно заменяет файлы |
| [`native-command/`](native-command/README.ru.md) | Запускает нативные для хоста команды без оболочки |
