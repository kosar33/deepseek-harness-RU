# dsh-brand

[English](README.md) | [中文](README.zh.md) | Русский

Примитив номинальной типизации `Branded<B>` — крошечный, **чисто типовой** пакет (без рантайм-кода и без зависимостей от пакетов harness), разделяемый каждым пакетом, владеющим межграничным идентификатором.

## Что такое `Branded`

Бренд делает структурно одинаковые строки невзаимозаменяемыми на уровне типов: `SessionId` нельзя передать там, где ожидается `CallId`, хотя в рантайме оба значения — обычные `string`.

```ts
import type { Branded } from '@deepseek-ai/dsh-brand'

export type SessionId = Branded<'SessionId'>

/** Brand a string as a SessionId (a plain cast — zero runtime cost). */
export function SessionId(id: string): SessionId {
  return id as SessionId
}
```

Конструирование идёт через фабрику конкретного id в пакете-владельце. Сравнение, журналирование, JSON-сериализация и формат протокола ведут себя как для обычной строки; бренд стирается при компиляции.

## Политика: брендировать идентификаторы, пересекающие границы пакетов

Пакет брендирует те id, которыми владеет, — `CallId` в `dsh-llm`, общий для агента и сессии `SessionId` в `dsh-session`, `JobId` в `dsh-jobs`. Брендируйте межпакетные идентификаторы, которые действительно можно перепутать; не каждой строке нужен бренд.

Этот пакет владеет только самим примитивом. Отсутствие зависимостей позволяет, например, `dsh-jobs` брендировать `JobId` без импорта постороннего пакета возможности лишь ради `Branded`.
