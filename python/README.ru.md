# Python SDK для DeepSeek Harness

[English](README.md) | [中文](README.zh.md) | Русский

Пакеты Python для управления DeepSeek Harness как дочерним процессом. Клиентский SDK общается с bundled-рантаймом по stdio через JSON-RPC, в котором сообщения разделены переводами строк.

## Пакеты

| Каталог | Дистрибутив / модуль | Роль |
|---|---|---|
| [sdk](sdk/README.ru.md) | `deepseek-harness-sdk` / `deepseek_harness` | Высокоуровневый API ходов и низкоуровневый клиент JSON-RPC |
| [sdk-runtime](sdk-runtime/README.ru.md) | `deepseek-harness-runtime-bin` / `deepseek_harness_runtime` | Bundled-бинарники рантайма и конфигурация агента по умолчанию |

## Поведение

SDK запускает соответствующий bundled-рантайм, если вызывающий не выбрал явный канал. Канал выбирает клиент и передаёт конфигурацию по умолчанию; самому рантайму всегда требуется явная конфигурация. Полными контрактами выбора рантайма и конфигурации владеют [справочник SDK](sdk/README.ru.md) и [справочник носителей рантайма](sdk-runtime/README.ru.md).

## Воркфлоу для контрибьюторов

[Воркфлоу для контрибьюторов Python](development.ru.md) охватывают сборку артефактов рантайма, проверку пакетов, разработку из исходников и подготовку дистрибутивов.
